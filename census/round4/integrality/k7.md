# K7: the exact excursion map, the sharpest excursion inequality, and where induction breaks (task 3)

Lens "integrality", round 4. Check: `check_k7.py` (exits 0, about 3 s).

K7 (round3/accel/sfamily_obst.md) acts on z >= 0:
z even → z/2; z ≡ 3 (mod 4) → (3z+1)/2; z ≡ 1 (mod 4) → (z−1)/4.
It is the z-form of the S-family core sf3_7. Its only known cycle is the
fixed point 0. It is type (c) (expanding fixed point −1, multiplier 3/2, in the
SCC of the contracting part) and OBST.

## K1. The excursion map. PROVED

Write an odd z as z = 2^j u − 1 with u odd and j >= 1. Then the first j−1 steps
are (3z+1)/2, step j is (z−1)/4, and

    K7^j(z) = (3^{j−1} u − 1)/2.

Then halvings follow until the value is odd. So the next odd value is

    S(z) = (3^{j−1} u − 1) / 2^v,    v = v_2(3^{j−1} u − 1) >= 1,

with S(1) = 0. *Proof.* If z ≡ −1 (mod 2^i) with i >= 2 then
(3z+1)/2 = 3(z+1)/2 − 1 ≡ −1 (mod 2^{i−1}). Induct, then apply (z−1)/4 to
2·3^{j−1}u − 1 ≡ 1 (mod 4). ∎ Compare 3x+1, whose odd map in the same
coordinates is 2^j u − 1 ↦ odd part of 3^j u − 1. **K7 is 3x+1 with one factor
3 removed from every excursion.**

## K2. The sharpest excursion inequality. PROVED

For every odd z = 2^j u − 1:

    S(z) + 1/2 <= (3^{j−1}/2^{j+1}) (z + 1)    (equality iff v = 1),
    S(z) <= ((z+1)^{log_2 3} − 3)/6             (equality iff u = 1, v = 1, i.e. z = 2^j − 1 with j even).

*Proof.* 2S + 1 <= 3^{j−1}u because v >= 1, with equality iff v = 1, and
3^{j−1}u = (3^{j−1}/2^j)(z+1). For the second line, the integrality constraint
is j <= log_2(z+1) (a positive integer ≡ −1 mod 2^j is >= 2^j − 1), and
3^{j}u <= 3^{j} u^{log_2 3} = (2^j u)^{log_2 3} with equality iff u = 1. For
z = 2^j − 1, v = v_2(3^{j−1} − 1) is 1 iff j−1 is odd. ∎

Both lines are attained, so neither can be improved as a function of (j, z) or
of z alone. The first is the cylinder information. The second is all that
integrality adds: one excursion can raise z to at most about z^{1.585}/6.
**S(z) < z whenever j <= 4**, because u(2^{j+1} − 3^{j−1}) > 1 for j <= 4
(32 > 27). Only z ≡ −1 (mod 32) can rise in one excursion.

## K3. Where strong induction on z breaks. PROVED

Strong induction ("every z has an iterate below z") closes at once on every z
outside

    B1 = {odd z : S(z) >= z} = {z = 2^j u − 1 : 2^v (2^j u − 1) <= 3^{j−1} u − 1}.

For each (j, v), u runs over one class modulo 2^{v+1}. The condition holds for
all but finitely many such u when 2^{j+v} < 3^{j−1}, and for only finitely many
when 2^{j+v} > 3^{j−1}. So B1 has density

    δ1 = Σ_{j>=5} 2^{−j} Σ_{v>=1, 2^{j+v}<3^{j−1}} 2^{−v} = 0.0362745… among odd z

(an exact rational partial sum to j = 400, plus a tail bound 2^{−399}; a direct
count below 2^22 gives 0.0362749; the earlier "0.036275…" read as a truncation and is corrected to 0.0362745…). On B1 the induction needs a second
excursion, and so on. It never closes after a bounded number of excursions.
For every k there is an explicit z whose first k excursions all have j = 6,
v = 1 and all rise by the factor about 243/128 (check [K5] builds them for
k <= 8 by 2-adic lifting: each excursion fixes 7 more bits). This is Theorem N
in excursion coordinates. By Theorem M of `mixing.md`, the excursion data
(j_i, v_i) are i.i.d. (j and v independent geometric with ratio 1/2) under
2-adic Haar measure and on positive integers in every finite window, so no
finite amount of information about z rules out a further rise.

**Where exactly it stalls.** For the induction to close one needs, for each z,
some k with Σ_{i<=k} [(j_i − 1) log 3 − (j_i + v_i) log 2] < −log(1 + O(1/z)).
The mean of the summand under Haar measure is (2−1) log 3 − 4 log 2 ≈ −1.674.
So K7 contracts strongly on average, much more than 3x+1 (−0.29 per
odd step). But bounding the *partial sums for every integer z* is exactly
the problem Theorem N says no cylinder argument solves. The integrality bound
K2 only caps each summand by (log_2 3 − 1) log(z+1), which is a bound on how
fast an orbit can grow, not on whether it falls.

## K4. What integrality does give for K7. PROVED

From `cycles.md` (Corollary C1, with the 10^11 verification): **every K7 cycle
other than 0 has all elements >= 5·10^10 and length >= 190537.** Round 3 had
