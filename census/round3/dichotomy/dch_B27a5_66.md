# dch_B27a5_66

**Rule.** 3|n -> n/3; n mod 27 in {2,4,16,17,23} -> 5n+1; other 3 not| n -> n+1.

As a table map (Q = 27): n mod 27 in {0,3,6,9,12,15,18,21,24} -> (n)/3; n mod 27 in {1,5,7,8,10,11,13,14,19,20,22,25,26} -> n+1; n mod 27 in {2,4,16,17,23} -> 5n+1.

**Question (GLOBAL).** Is every positive orbit eventually periodic, and what are the cycles?

**Answer.** Yes. There are exactly 2 cycle(s): (1 2 11 12 4 21 7 8 9 3), (28 29 146 147 49 50 251 252 84).

**Status.** PROVED (Theorem 2 of dichotomy.md, with the integer certificate below). 

## Proof

(H1), (H2) and (P) hold, so Theorem 1 of dichotomy.md applies. decide.py found integer weights c(r) for r mod 27 with c(s)·u_r < c(r)·w_r on every edge r → s of the residue graph. The weights have 60-bit size and are printed by `python3 decide.py --id dch_B27a5_66`. Each of the 45 edge inequalities is checked with integers, and the largest edge ratio is θ = 0.991909 < 1. By Theorem 2, V(n) = c(n mod 27)·n strictly decreases except on the finite set F = {n : V(Tn) ≥ V(n)}. F is contained in {n ≤ 122} (symbolic bounds N_r) and has 65 elements, the largest being 122. Every orbit meets F and every cycle meets F. Iterating each element of F until it repeats gives exactly the cycles listed above. ∎

## Difficulty

* The minimal stopping depth is **k\* = 66** (Theorem 3). Every plain descent certificate T^j(n) < n on residue classes needs some class with j ≥ 66, and one with max j = 66 exists. The minimal certificate has 303 leaves when residues mod 27 are distinguished.
* Witness for the lower bound: the progression n ≡ 125524238453 (mod 2541865828329) (modulus has 42 bits). On it, T^i(n) ≥ n for every i < 66 at all large n. `check_systems.py` verifies this at n = a + M·10^12 by direct iteration.
* The reason is the max-mean cycle of the residue graph: length 9, multiplier 25/27 ≈ 0.925926, mean log-multiplier -0.008551 per step. It contracts, but only barely, so by Theorem 3(c) the depth is large. The a-priori depth bound from the potential is 396.
* A one-step weighted potential nevertheless proves GLOBAL, so on the census scale this is tier 2 (descent plus a finite table). The depth matters only for plain certificates. For comparison, the round-2 depth record desc_s32_max has k = 44.
