# c62_64_s27: accelerated 3x+1 (average contraction) with one class changed

**Rule.** T(n) = n/2 for even n, (3n+1)/2 for odd n, **except** T(n) = 4n+5 for
n ≡ 62 (mod 64). T is non-injective: T(253) = 380 = T(760). Over one period of
64 classes, the product of slopes is 3^32·4 / 2^63 < 1. So the Haar-average
log-slope is negative: the map contracts on average, as the Collatz map does.

**Question.** FATE of 27. For the unchanged Collatz map, 27 reaches 1 after 111
steps.

| claim | status | tier |

| every n in U = {41, 62, 124, 190, 253, 318, 380, 446} (mod 512) has an unbounded orbit (ascent trap) | PROVED | 2 (but see below) |
| a non-monotone *aperiodic* trap for an average-contracting single-class change of this map | not found (m ≤ 6, K ≤ 2^{m+4}) | EVIDENCE |

## Proof

27 → 41 → 62 → 253. On the class n ≡ 253 (mod 512):
(3n+1)/2 ≡ 380 (mod 768), then /2 gives a value ≡ 190 (mod 384), which lies in
62 (mod 64), and then 4x+5. So T³(n) = 4·(3n+1)/4 + 5 = 3n + 6, and
3n + 6 ≡ 253 (mod 512) again. Hence T^{3k}(253) = 3^k·256 − 3 for k ≥ 0, a strictly
increasing subsequence, and each 3-step block contains the fall 380 → 190.

The trap statement uses Lemma A↑ on the 8-class set U mod 512, whose witness is
checked exactly. Lemma F gives the forced falls.

## Honest assessment

This is the requested non-injective map with average contraction and a provably
infinite, non-monotone orbit. Its proof is a **tier-1 affine pump**. The trap U
has a closed walk with 2-adic unit product, namely the pump itself, so Lemma I
does not apply (the check asserts this). In searches over single-class changes
(modulus ≤ 64, rules (a n + b)/d with a ≤ 9, d ∈ {1,2,4}, b < 12, trap moduli
≤ 2^{m+4}; `scratch/searchall.py`), every ascent trap with forced falls for the
accelerated 3x+1 map was of this pumped kind. None was aperiodic.

Heuristically, an aperiodic trap must lose 2-adic precision. Lost precision
spreads a trap class over many classes, and for an average-contracting map some
of those carry contracting cycles. Making this precise would be a
Lemma-P-type theorem for maps with refining branches (even numerators). I did
not prove it, so it is recorded as OPEN.
