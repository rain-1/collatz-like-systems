# Theorem A: the progression theorem for p-shift maps

**Status: PROVED** (complete proof below; finite hypotheses checked by `certify.py`, the whole
proof executed constructively by `construct.py`; check: `check_theorem_A.py`).

Two starts *merge* if their forward orbits share a value (zero iterates allowed); merging
classes are the classes of the generated equivalence relation. The question is which arithmetic
progressions a merging class meets. The answer is: exactly those allowed by one explicit,
computable finite invariant.

## 1. Setting

A **p-shift map** is given by a prime p, an integer κ ≥ 1 and pairs (u_r, v_r) for
r ∈ Z/p^κ with u_r ≥ 1, p ∤ u_r and p | u_r r + v_r:

    T(n) = (u_r n + v_r)/p    for n ≡ r (mod p^κ),

and we assume T maps positive integers to positive integers. Notation:

* U = the primes dividing some u_r ("numerator primes"); a prime is *good* if it is not p and
  not in U.
* Σ = Z/p^{κ-1}, the set of *states*; the state of n is n mod p^{κ-1} (one state when κ = 1).
* B_r(n) = (u_r n + v_r)/p. The *move* r is the inverse branch P_r(z) = (p z − v_r)/u_r.

**Hypotheses** (all are finite checks, carried out by `certify.py`):

* **(A1) dilation.** (u_r, v_r) = (1, 0) for every r ≡ 0 (mod p); i.e. T(p m) = m for all m.
* **(A0) connectivity.** The state graph (edge σ → r mod p^{κ-1} for each move r admissible
  at σ, see Lemma 3) is strongly connected.
* **(IA) initial accessibility.** If U ≠ ∅: no move has u_r ≠ 1 with some ℓ ∈ U not dividing
  u_r (no "mixed" moves), the IA game of §4 has a nonempty live set, and the entry condition of
  Lemma 5 holds.

Moves with r ≡ 0 (mod p) are called D (dilations), moves with u_r = 1 and r ≢ 0 are I
(isometric), moves with every ℓ ∈ U dividing u_r are E (expanding).

**Lemma 0 (shortcuts).** Let R be a map with R(n) = n/p on multiples of p and R(n) = u_r n + v_r
on the other classes, where p | u_r n + v_r there. Its shortcut S(n) = (u_r n + v_r)/p on those
classes and S(n) = n/p on multiples of p satisfies S(n) ∈ {R(n), R²(n)}, and on the non-multiples
R(n) is a multiple of p with S(R(n)) = S(n). Hence R and S have the same merging classes and
the same cycles up to the inserted values u_r n + v_r. *Proof:* immediate from the formulas. ∎

All census maps in `systems.py` are given in shortcut form; the raw rule is recorded beside each.

## 2. Cylinders and the lift lemma

**Lemma 1 (cylinders).** For a word W = (r_0, …, r_{t-1}) the set D_W of integers n with
T^i(n) ≡ r_i (mod p^κ) for i < t is empty or a single class modulo p^{κ+t-1}, and on it T^t is
n ↦ (a_W n + b_W)/p^t with a_W = ∏ u_{r_i}.

*Proof.* Induction on t. If D_{(r_1..r_{t-1})} = c + p^{κ+t-2}Z, then n ∈ D_W iff n ≡ r_0
(mod p^κ) and (u n + v)/p ≡ c (mod p^{κ+t-2}), i.e. n ≡ u^{-1}(pc − v) (mod p^{κ+t-1}); this
class is compatible with n ≡ r_0 (mod p^κ) or not. ∎

**Lemma 2 (lift).** Let x ≥ 1, t ≥ 0, c = T^t(x) and a = ∏_{i<t} u_{r_i} along the orbit of x.
For every integer y ≥ c with y ≡ c (mod a p^{κ-1}),

    n = x + p^t (y − c)/a

is a positive integer with T^t(n) = y. If moreover y ≡ c (mod a p^{κ-1} N') with p ∤ N' and
t + κ − 1 ≥ e, then n ≡ x (mod p^e N').

*Proof.* Write y − c = a p^{κ-1} j. Then n = x + p^{κ+t-1} j lies in the cylinder of x
(Lemma 1), so T^t(n) = c + (a/p^t)(n − x) = y. The intermediate values are T^i(x) +
(a_i/p^i) p^{κ+t-1} j ≥ T^i(x) > 0, so every step is a step of T on positive integers. The
congruence: n − x = p^{κ+t-1} N' j'. ∎

## 3. Moves, the groupoid, and the invariant

**Lemma 3 (moves).** For integers z, P_r(z) is an integer with T(P_r(z)) = z iff
(i) z ≡ B_r(r) (mod p^{κ-1}) (the *state condition*: the move is admissible at the state of z)
and (ii) u_r | p z − v_r (the *U-domain condition*). The output has state r mod p^{κ-1}. Modulo
a good Q the move acts as the bijection z ↦ (pz − v_r) u_r^{-1}. A D or I move has no U-domain
condition. *Proof.* P_r(z) ≡ r (mod p^κ) iff p z − v_r ≡ u_r r (mod p^κ) iff (i); integrality is
(ii); then T(P_r(z)) = B_r(P_r(z)) = z. ∎

For a good modulus Q let 𝒢_Q be the directed graph on Σ × Z/Q with an edge
(σ, ρ) → (r mod p^{κ-1}, P_r(ρ)) for every move r admissible at σ.

**Lemma 4 (groupoid).** (a) Under (A0), reachability in 𝒢_Q is symmetric; its classes are the
weakly connected components. (b) Let t_1, …, t_m ∈ Z[1/pU] be translation amounts of elements
of the group generated by the loops at state 0 (each loop = a word of moves from state 0 back
to state 0, acting on Q by an affine map), and let δ = gcd of the good parts of the numerators
of the t_i. Then for every good Q, every class of 𝒢_Q is a union of cosets
(σ, ρ + gcd(δ, Q) Z/Q). Consequently the classes of 𝒢_Q are the preimages of the classes of
𝒢_{gcd(δ,Q)}, and the partition of Σ × Z/δ into classes of 𝒢_δ determines all of them.

*Proof.* (a) Each edge label is a permutation of Z/Q. If a word w leads from (σ, ρ) to
(σ', ρ'), take by (A0) a word w' from σ' to σ; the loop w'w at σ acts by a permutation π of
finite order k, and following w' then (w w')^{k-1} from (σ', ρ') returns to (σ, π^k ρ) =
(σ, ρ). (b) The loops at 0 act on Z/Q through a finite group; the closure of the set of loop
permutations under composition is that group, so every element (with inverses) is realised by an
actual loop. A translation by t acts on Z/Q as translation by the unit multiple of the good part
of t, which generates gcd(good(t), Q)Z/Q. Conjugating by a word from 0 to σ (an affine map with
unit slope mod Q) transports this to every state. ∎

Define the **invariant** g(n) := class of (n mod p^{κ-1}, n mod δ) in 𝒢_δ.

**Lemma 4' (invariance).** g(T(n)) = g(n) for every n ≥ 1, and g is a function of
(n mod p^{κ-1}, n mod d*) for the least such divisor d* | δ (computed). *Proof.* With
n ≡ r (mod p^κ), n = P_r(T n), so the move r is an edge from (state of T n, T n mod δ) to
(state of n, n mod δ); both lie in one class by (a). ∎

Under (A1) with κ = 1, translations always exist: the dilation loop z ↦ pz and the one-move loop
P_r for a branch with v_r ≠ 0 (there is one, since p ∤ u_r r for r ≢ 0) have commutator
translation (p − 1)(−v_r/u_r) ≠ 0. For κ ≥ 2 we do not claim this in general; `certify.py` found
translations, hence a finite δ, for every system considered.

## 4. The IA game (initial accessibility)

Fix ℓ-adic precision through L_U = ∏_{ℓ∈U} ℓ^{max_r v_ℓ(u_r)} and L2 = L_U². Nodes of the game
are (σ, z) ∈ Σ × Z/L2. An *option* at a node is a word of D/I moves admissible from it followed by
one E move r admissible at the resulting node with u_r | p z_1 − v_r; its *outcome* is the set
of all nodes (r mod p^{κ-1}, z') with z' ≡ P_r(z_1) (mod L2/u_r) (P_r(z_1) is determined modulo
L2/u_r ≥ L_U). The *live set* is the greatest set of nodes each of which has an option whose
outcome lies in the live set (computed by iterated deletion). A residue z mod L2 is *enterable*
if (0, p^h z mod L2) is live for some h ≥ κ − 1.

Fix a good Q. Call (σ, ρ) **fully accessible for y** if for every s ≥ 0 and every residue
τ modulo ∏_{ℓ∈U} ℓ^s there are arbitrarily large ancestors z of y with state σ, z ≡ ρ (mod Q)
and z ≡ τ (mod ∏ ℓ^s).

**Lemma 5 (IA).** Assume (A1) and that the live set is nonempty. If y is enterable then some
pair (σ, ρ) is fully accessible for y. If U = ∅ every (0, p^h y mod Q) is fully accessible.

*Proof.* Let o = ord_Q(p), O = lcm(o, ord_ℓ(p) for ℓ ∈ U, and 2 if 2 ∈ U), and
J_ℓ = v_ℓ(p^O − 1) (≥ 1; ≥ 2 if ℓ = 2). Since p^O ∈ 1 + ℓ^{J_ℓ}Z_ℓ with exact valuation J_ℓ, the
closure of {p^{Oi}} in Z_ℓ^× is 1 + ℓ^{J_ℓ}Z_ℓ; jointly over ℓ ∈ U the closure is the product
(the ℓ-adic logarithms are generators of the factors ℓ^{J_ℓ}Z_ℓ, and Z is dense in ∏ Z_ℓ).
Choose h_0 ≥ κ − 1 with (0, p^{h_0} y mod L2) live. The integers p^h y with h ≡ h_0 (mod O),
h large, are ancestors of y (D moves) with state 0 and fixed residue ρ_0 = p^{h_0} y mod Q,
and their U-adic closure is the ball B_0 = p^{h_0} y (1 + ∏ ℓ^{J_ℓ}Z_ℓ), i.e. the product of
the balls of radius ℓ^{-(J_ℓ+v_ℓ(y))}.

*Ball growing.* Maintain a product of balls B = ∏ B(c_ℓ, ℓ^{-j_ℓ}), a state σ and a residue
ρ mod Q such that every residue class contained in B is met by arbitrarily large ancestors of y
with state σ and residue ρ ("B is realised at (σ, ρ)"), and such that the node
(σ, c mod L2) is live whenever all j_ℓ ≥ v_ℓ(L2). Apply the option of a live node: I and D moves
are bijections of Z_ℓ (z ↦ pz − v) and map balls onto balls of the same radius, keeping the
realisation (prescribe the preimage class). For the E move r: if j_ℓ ≥ v_ℓ(u_r) the ball lies
in the domain coset {u_r | pz − v_r} (its centre does), and P_r maps it onto the ball of radius
ℓ^{-(j_ℓ − v_ℓ(u_r))}; if j_ℓ < v_ℓ(u_r) the ball contains the whole domain coset, whose image is
Z_ℓ. Realisation transfers: to hit a target class of the image, prescribe its preimage class
(precision raised by v_ℓ(u_r)), which lies in B. Every positive j_ℓ decreases by at least one.
If after the move some j_ℓ < v_ℓ(L2), the new ball contains every lift (modulo L2) of the known
residue of the new centre, or is contained in that set of lifts; all those lifts are live by the
choice of option, so we re-centre the ball at a live residue (any point of a ball is a centre).
(Only the centre needs a live option: D/I words depend only on the state, so they apply to the
whole ball; for the E move the ball either lies in the domain coset or contains it, and the image
ball contains the whole outcome set of the centre's option, which is inside the live set, so a
live re-centring always exists. Every positive j_ℓ drops by v_ℓ(u_r) ≥ 1 because no move is
mixed.) Note that the initial radius ℓ^{-(J_ℓ+v_ℓ(y))} depends on v_ℓ(y), so the number of E
moves grows with v_ℓ(y); this is harmless here (y is fixed) but matters for uniform bounds, see
Lemmas C2' and R of `theorem_C_counting.md`.
After finitely many E moves every j_ℓ = 0: B = ∏ Z_ℓ is realised at some (σ, ρ). This is the
definition of full accessibility. Q-residues: moves act on Z/Q by fixed permutations, so ρ is
determined. Positivity and size: all maps have positive slope, so taking h large makes every
intermediate value positive and the output as large as wanted. ∎

**Lemma 6 (closure).** If (σ, ρ) is fully accessible for y and the move r is admissible at σ,
then (r mod p^{κ-1}, P_r(ρ)) is fully accessible for y.

*Proof.* Given s and τ, take an ancestor z with state σ, z ≡ ρ (mod Q) and
z ≡ (u_r τ + v_r) p^{-1} (mod ∏ ℓ^{s+v_ℓ(u_r)}). Then u_r | p z − v_r, so P_r(z) is an ancestor
(Lemma 3) with the new state, residue P_r(ρ) mod Q, and P_r(z) ≡ τ (mod ∏ ℓ^s). ∎

**Entry.** Every merging class contains an enterable point if (E1) for every E move r all
residues mod L2 of the images B_r(n), n ≡ r (mod p^κ), are enterable, and (E2) every cycle of T
that uses only D and I branches contains an enterable point. Indeed an orbit that never uses an
E branch uses only branches with u_r = 1 < p (no X moves under (IA)), which satisfy
T(n) < n for n > Bnd := max v_r/(p − 1), and [1, Bnd] is mapped into itself by them; so such an
orbit ends in one of the finitely many D/I-cycles inside [1, Bnd] (enumerated exactly). Or every
residue is enterable (then (E1), (E2) are not needed).

## 5. The theorem

**Theorem A.** Let T be a p-shift map satisfying (A1), (A0) and (IA). Let H be any merging class
(including a hypothetical divergent one) and x ≥ 1 with g(x) = g(H). Then for every N ≥ 1 the
progression x (mod N) contains arbitrarily large members of H. Conversely, H is contained in
{n : g(n) = g(H)}. Hence:

1. the progressions meeting H are exactly those containing an integer of invariant g(H);
2. g is the finest T-invariant function of n mod M (any M): every such function is a function of
   g (the *profinite invariant*), and it is computed exactly by the algorithm below;
3. every positive orbit is eventually periodic iff every n in one progression P is eventually
   periodic, for any P meeting all g-classes: e.g. any x mod N with gcd(N, p^{κ-1}·d*) = 1
   (by CRT it meets every residue mod p^{κ-1}d*, on which g depends), so 1 mod N with
   gcd(N, d*) = 1 when the invariant is state-free; or any progression at all when there is a
   single class. *(Corrected after REFEREE1:* the first version gave "1 mod (p^{κ-1}·d*)·m",
   which lies in a single g-class and is wrong whenever there are several classes; the corrected
   example is tested on all 33 systems in `check_sufficient_sets.py`.)

*Proof.* Choose y ∈ H enterable (Entry). Write N = p^e N_U Q_0 with N_U a product of powers of
primes of U and Q_0 good; set Q = lcm(Q_0, δ). By Lemma 5 some (σ_1, ρ_1) is fully accessible for
y. By Lemma 6 every pair reachable from it in 𝒢_Q is fully accessible; by Lemma 4 these are all
pairs whose class mod δ equals that of (σ_1, ρ_1 mod δ), i.e. all pairs with invariant g(y) = g(H).
Take t = max(0, e − κ + 1), c = T^t(x), a as in Lemma 2. Since g(c) = g(x) = g(H), the pair
(state of c, c mod Q) is fully accessible: there are arbitrarily large ancestors y_2 of y with
y_2 ≡ c (mod p^{κ-1}), y_2 ≡ c (mod Q) and y_2 ≡ c (mod a N_U) (U-adic precision v_ℓ(a N_U)).
Then y_2 ≡ c (mod a p^{κ-1} N_U Q_0) and Lemma 2 gives n ≡ x (mod N), n ≥ x arbitrarily large,
with T^t(n) = y_2, an ancestor of y. The converse is Lemma 4'. Item 2: a function f of n mod M
with f(Tn) = f(n) is constant on merging classes; if g(x) = g(x') the class of x meets
x' + M Z, so f(x) = f(x'). Item 3: if every member of P is eventually periodic and H is any
class, H meets P, and merging with an eventually periodic orbit makes an orbit eventually
periodic. ∎

**Corollary (where the earlier results sit).** For split5_3 the algorithm returns d* = 3 with
two classes (3 | n and 3 ∤ n): Theorem 1 of `../../round2/rewriting/split5_3_components.md`.
For split_5 it returns divisibility by 5 (`../../results/split_5_s27.md`). For qrB7_c53 it returns
the three classes 0 / squares / non-squares mod 7 (`../../round2/qr/qrB7_c53.md`). For the
Σ_d split maps of the concurrent lens `../deep/basins.md` it returns the ⟨2,3⟩-classes mod d (we
re-derive their tables for split_13, 73, 97, 7081, splitB_7, 71 independently).

## 6. The algorithm and its proof object

`certify.py`, for a table (p, κ, (u_r, v_r)):

1. validates the table and checks (A1), (A0);
2. builds the moves, a BFS tree of the state graph, and one loop at state 0 through every move;
3. computes all pairwise commutators of loops exactly (rational affine maps) and records a
   subset whose translation amounts have good-part gcd δ (the *proof object* for Lemma 4b);
4. computes the classes of 𝒢_δ by BFS, verifies that every move preserves them (symmetry), and
   finds the least modulus d* and whether the state matters;
5. plays the IA game modulo L2 = L_U² (greatest fixed point), computes the enterable residues,
   the E-image residues, and the D/I-cycles below Bnd (exact enumeration);
6. lists the given cycles with their class and lap numerator.

All of this is finite. `construct.py` executes the proof of Theorem A literally (entry point,
ball growing with the live options, BFS word in 𝒢_Q, backward propagation of the U-adic target,
the dilation exponent by an exact Pohlig–Hellman discrete logarithm and CRT, replay, lift) and
`verify` replays T exactly to confirm n ≡ x (mod N) and that n merges with y.

## 7. Which hypotheses are needed (counterexamples)

* **p | u (no cylinder bijection).** T(n) = n/2 (n even), 2n (n odd) is not a p-shift map
  (u = 2 = p). Its merging classes are {m 2^k}. The residue graph modulo 8 is weakly connected
  (0→0,4; 4→2,6; 2→1,5; 6→3,7; 1→2; 3→6; 5→2; 7→6), so no invariant modulo 8 separates
  anything, yet the class of 1 is {1, 2, 4, 8, …} and misses 3 mod 8. Its finest invariants are
  the cosets of ⟨2⟩ modulo every odd M, an infinite (non-finite-modulus) invariant. Checked in
  `check_theorem_A.py`.
* **No dilation (A1 fails).** The 1932 permutation (3q→2q, 3q+1→4q+1, 3q+2→4q+3) is a 3-shift
  map with u_0 = 2: merging classes are single orbits, and the finite cycles (1), (2 3),
  (4 5 7 9 6), (44 …) meet only finitely many residues, while the finest finite-modulus invariant
  is trivial (residue graph strongly connected modulo every M, `../../lhf/perm-swap-c/CLS-038.md`);
  so the conclusion of Theorem A fails. *(Corrected after REFEREE1:* the first version said "no
  sufficiency statement can hold"; that was false.) Exactly two progressions are sufficient,
  ℤ_{≥1} and 1 mod 2 (every forward orbit contains an odd number), and no progression with
  N ≥ 3 is: Proposition P0 of `sufficient_sets.md` §4.
* **Two independent denominators (not a p-shift).** div2_3n (n/2, else 3n): classes
  {m 2^a 3^b} with m coprime to 6; meets exactly m⟨2,3⟩ mod M at every M (so "sufficiency at each
  level" holds) but the invariant is the coset of the 6-free part in an infinite profinite
  quotient, and counts are O((log X)²). Checked numerically in `check_theorem_A.py`.
* **IA fails.** For 3n+3, 3n+9, 5n+5, 7n+7 every expanding image is divisible by the numerator,
  and the IA game has no enterable image. We do not claim the conclusion fails there (these maps
  restricted to dZ are conjugate to 3x+1, 5x+1, 7x+1, for which Theorem A holds); the hypothesis
  is sufficient, not necessary. No counterexample to the conclusion inside the p-shift class with
  (A0), (A1) is known to us: OPEN whether (IA) can be dropped.

## Novelty

**The 3x+1 case is published.** For the 3x+1 map (trivial invariant) the statement "every
arithmetic progression is sufficient" (every merging class / every orbit's component meets every
progression) is K. M. Monks, *The sufficiency of arithmetic progressions for the 3x+1
Conjecture*, Proc. Amer. Math. Soc. 134 (2006) 2861–2872, doi:10.1090/S0002-9939-06-08567-4. We
know its content from the introduction of Monks–Monks–Monks–Monks, *Strongly sufficient sets and
the distribution of arithmetic sequences in the 3x+1 graph*, arXiv:1204.3904, whose introduction
says "In [9], the third author shows that every arithmetic sequence is sufficient", with [9] =
"Monks, K. M., The sufficiency of arithmetic progressions for the 3x+1 conjecture, Proc. Amer.
Math. Soc., 134 (10), October (2006), 2861-2872" (read in the ar5iv rendering of arXiv:1204.3904
during this repair; the PAMS article itself was not accessible, so its exact definitions, statement
and method are not quoted). arXiv:1204.3904 also constructs sufficient sets of arbitrarily low
density for 3x+1 and analyses the groups generated by the two inverse maps modulo b coprime to 6.
So the 3x+1 case of Theorem A (item 3 with a single class) is not new; we cannot say how close
our route is to Monks's without reading the article. The general p-shift theorem with an algorithmically computed
invariant, the IA game, the counterexamples of §7 and the census applications: novelty not
checked beyond this.
