# swT3_9_15_s8

**Rule.** Q(n) = sigma(T(n)), where sigma swaps 3 <-> 4 (mod 6), that is, 3,9,15 <-> 4,10,16 (mod 18). So Q(n) = T(n)+1 if T(n) = 3 (mod 6), Q(n) = T(n)-1 if T(n) = 4 (mod 6), and Q(n) = T(n) otherwise. |Q - T| <= 1, and Q is a permutation of Z_{>0}.

**Question (FATE).** What is the fate of the seed 8?

| answer | status | tier |
|---|---|---|
| infinite; the orbit is strictly increasing | PROVED | 1 |

## Proof

Let n not be a multiple of 3. Then T(n) is 4q+1 or 4q+3, which is odd. sigma raises odd numbers = 3 (mod 6) by 1 and fixes all other odd numbers, so Q(n) is T(n) or T(n)+1. We check that Q(n) is not divisible by 3:
- If Q(n) = T(n), then 3 | T(n) together with T(n) odd and T(n) != 3 (mod 6) is impossible.
- If Q(n) = T(n)+1, then T(n) = 3 (mod 6) and Q(n) = 4 (mod 6).

Hence the non-multiples of 3 form a Q-closed set. On that set Q(n) >= T(n) >= (4n-1)/3 > n for n >= 2. Now 8 is not a multiple of 3 and Q(8) = 11 > 8, so the orbit of 8 is strictly increasing and infinite.

**Remark (CYCLES, also tier 1).** The only cycle of Q is {1}.
- On 3Z, Q(3q) is in {2q-1, 2q}, which is less than 3q.
- Take a cycle with minimum m. If 3 | m, then Q(m) < m, a contradiction.
- If 3 does not divide m and m >= 2, then every later term is a non-multiple of 3 and increases strictly, so the orbit never comes back to m.

So every orbit other than {1} is a bi-infinite line. In forward time it descends through multiples of 3, then rises forever.

## Why this is the easy side

This is the tier-1 vertex of the cube sigma_A o T, A ⊆ {3,9,15} (see swT9_15_s8.md). The swap removes exactly the possible re-entries of a rising orbit into the falling class 3Z. Under T, a rising step produces a multiple of 3 for one third of the inputs, and which inputs those are depends on high 3-adic digits. That re-entry mechanism is the feature that makes T hard. Tier 0 cannot prove that an orbit is infinite.

## Referee

**Verdict: CONFIRMED, tier 1 (agreed).**

Re-derivation: for 3 ∤ n, T(n) is odd, and sigma_{3 mod 6} only changes odd values ≡ 3 (mod 6), moving them to ≡ 4 (mod 6). So 3 ∤ Q(n), and Q(n) ≥ (4n-1)/3 > n for n ≥ 2. Every orbit that leaves 3Z therefore increases forever.

On 3Z, Q(3q) = sigma(2q) ≤ 2q < 3q. So any cycle other than the fixed point {1} would have to stay inside 3Z and strictly decrease, which is impossible. The cycle list {1} is correct.
