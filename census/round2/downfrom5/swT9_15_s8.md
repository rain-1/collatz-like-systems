# swT9_15_s8

**Rule.** Q(n) = sigma(T(n)), where T is the 1932 permutation (3q->2q, 3q+1->4q+1, 3q+2->4q+3) and sigma swaps n <-> n+1 when n = 9 or 15 (mod 18). So Q(n) = T(n)+1 if T(n) = 9, 15 (mod 18), Q(n) = T(n)-1 if T(n) = 10, 16 (mod 18), and Q(n) = T(n) otherwise. In particular |Q(n) - T(n)| <= 1 for all n. Q is affine on each class mod 27, with slopes 2/3 (when 3 | n) and 4/3 (otherwise).

**Question (FATE).** What is the fate of the seed 8?

| answer | status | tier |
|---|---|---|
| infinite (never returns) | PROVED | 2 |

## Proof

(i) *Q is a bijection of Z_{>0}.* T is a bijection, and sigma is an involution of Z_{>0} (each swapped pair {18k+a, 18k+a+1} with a in {9, 15} consists of positive integers).

(ii) *The conjugate R = T o sigma.* Since sigma = sigma^{-1}, R = sigma o Q o sigma. So sigma(S) is Q-closed whenever S is R-closed. Write n = 36t + r. Reading the table of R (computed from the definition; each row is affine in t):

- falls (R(n) = 24t + c, c even) for r in {0,3,6,10,12,16,18,21,24,28,30,34};
- rises (R(n) = 48t + c, c odd) for every other r.

The odd falling residues are only r = 3 (R = 24t+2) and r = 21 (R = 24t+14). Both outputs are 2 (mod 12).

Let S = {n odd} ∪ {n = 2 (mod 12)}. Then:
- an odd n either rises, giving an odd output, or has r in {3, 21}, giving an output of 2 (mod 12);
- n = 2 (mod 12) means r in {2, 14, 26}. All three rise, with outputs 48t+3, 48t+19 and 48t+35, which are odd.

So R(S) ⊆ S.

(iii) *Certificate for Q.* S' = sigma(S) = {n : sigma(n) odd or sigma(n) = 2 (mod 12)} is Q-closed. It is the union of 21 classes mod 36 listed by the check script. We have sigma(8) = 8, which is even and = 8 (mod 12), so 8 is not in S'. Also Q(8) = 11 is in S'.

(iv) *No return.* By induction Q^k(8) ∈ S' for all k >= 1, so Q^k(8) != 8. For an injective map this gives an infinite orbit: Q^i(8) = Q^j(8) with i < j would give 8 = Q^{j-i}(8).

**Consequences proved here.**
- The orbit is unbounded. A set of distinct positive integers is unbounded, so the orbit has infinitely many increases.
- The branch itinerary (the class mod 27 at each step) is not eventually periodic. *Lemma:* if a piecewise-affine map has an infinite orbit whose itinerary is eventually periodic with period word w, then on the tail x_{k+h} = A x_k + B for the composite A = prod of the slopes along w. If A has a nontrivial denominator 3^b, then x_{k+jh} - x* = A^j (x_k - x*), where x* = B/(1-A) is rational. Multiplying by the denominator of x* gives a nonzero integer N with 3^{bj} | N for every j, which is impossible. Every slope here is 2/3 or 4/3, so A has denominator 3^{|w|}.

**Not proved.** It is not proved that the orbit has infinitely many *decreases*. Numerically there are 340 falls in the first 3000 steps, the last at step 2986. Congruences cannot force them: 1 is a fixed point of Q in S', so the rise-only part of the trap's residue graph has a self-loop at every modulus. The same holds for every map whose rising branches have the form 3q+r -> 4q+s, because the fixed point 4r-3s of such a branch lies in its own class.

## Tier 2, and why tier 1 does not suffice

The certificate is a congruence invariant mod 36 that mixes the 2-adic and 3-adic structure, verified by a finite table. That is tier 2. Tier 1 fails on the following finite evidence (all of it checked exactly):

- *Monotonicity.* The orbit is not monotone (it falls at steps 3, 18, ...), and falls persist through 3000 steps. No eventually monotone tail is known.
- *Valuation bookkeeping.* No forward-closed union of residue classes separates 8 from Q(8) modulo 2^k (k <= 10) or 3^k (k <= 6). So no purely 2-adic or 3-adic invariant works. The smallest separating modulus is exactly 36: an exhaustive check finds none for K = 1..35.
- *Conjugacy.* Nothing short of the tier-2 certificate is known. This last point is evidence, not proof.

## Referee

**Verdict: CONFIRMED, tier 2 (agreed).**

I re-derived the trap for R = T∘sigma by hand from the mod-18 definition of sigma, without the mod-36 table:
- Odd n with n ≢ 9, 15 (mod 18) has sigma(n) = n. If 3 ∤ n then T(n) is odd. If n ≡ 3 (mod 18), T(n) = 2n/3 ≡ 2 (mod 12).
- n ≡ 9 (mod 18): sigma(n) = 18k+10 and T = 24k+13, which is odd. n ≡ 15 (mod 18): sigma(n) = 18k+16 and T = 24k+21, which is odd.
- n ≡ 2 (mod 12) has n mod 18 in {2, 8, 14}, so sigma(n) = n, and T(12k+2) = 16k+3, which is odd.

So S = odd ∪ {2 mod 12} is R-closed, 8 ∉ S, and R(8) = 11 ∈ S. Also Q^k(8) = sigma(R^k(8)), so Q returns to 8 iff R does. The no-return argument and the itinerary lemma are correct: the numerators are powers of 2, so 3^{bj} | N follows, and N ≠ 0 because the orbit is not periodic.

`referee_check.py` independently checks closure for n < 5400, plus the periodicity R(n+108) - R(n) ≡ 0 (mod 12). Together these make the check exhaustive.

Remark: the essential certificate is mod 12 on the conjugate R. "Minimal modulus 36" applies only to the presentation Q. It is still a mixed 2·3 modulus, and the verification is a congruence table, so the result is tier 2. I found no tier-1 argument. The orbit is not monotone, the trap is not a valuation statement (it needs the class mod 3 of the even members), and the explorer's exhaustive no-separator results for 2^k and 3^k are exact. The claim "1 is a fixed point in S', so congruences cannot force falls" holds for this trap.
