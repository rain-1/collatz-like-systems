# auto_1932_s8

**Map.** G(3q) = 2q, G(3q+1) = 4q+1, G(3q+2) = 4q+3. This is Collatz's 1932 permutation (round 1: perm_1932_s8).
**Question.** NONRETURN of 8: does G^n(8) ≠ 8 hold for every n ≥ 1?

**Answer.** OPEN. **Status:** OPEN. **Tier:** 5.

## Proved side result: no small automaton certificate exists

A *certificate* is a set C with G(C) ⊆ C, 8 ∉ C and G(8) ∈ C. Here C is any set recognised by a DFA reading canonical base-b digits most-significant first, with arbitrary behaviour on leading zeros.

* **Base 2: none with ≤ 11 states. Base 3: none with ≤ 11 states.** This was shown by SAT (CaDiCaL via python-sat, satlib.search). Every clause is a necessary condition on any certificate:
  * the 300 forward iterates G^n(8), n ≥ 1, are accepted;
  * the 300 backward iterates G^(−n)(8), n ≥ 0, are rejected;
  * n accepted ⇒ G(n) accepted, for every sample n ≤ 3000 (plus the orbit points).

  UNSAT at k therefore proves that no k-state certificate exists. The only symmetry breaking is δ(0,1) ∈ {0,1}, which is sound by relabelling. The search was run with kmax 16 (base 2) and 12 (base 3) and stopped once both reached k = 11.
* **Pure-Python re-verification in the check** (complete backtracking, same necessary constraints, exact closure test on survivors): base 2 ≤ 6 states, base 3 ≤ 4 states. This extends the ≤ 3 accessible states of certificate_search.py. `--sat` reruns the full bound.

## Why this is the expected picture (cited, not re-proved here)

* certificate_search_proofs.txt §5 (unreviewed) proves that the residue graph of G is strongly connected for every modulus. So no periodic certificate exists, and tiers 1–2 are excluded.
* The automaton theorem in auto_sfx7_s17.md needs the orbit to converge b-adically to an attracting cycle. G has slopes 2/3 and 4/3, which are not powers of a single base. It is a 2-adic and 3-adic mixing map, so that mechanism is unavailable. For the analogous 5n+p maps, binary_certificates_5np.pdf (unreviewed; uses Konieczny's Theorem B) proves that a binary regular forward-closed set is periodic up to density zero on units. The SAT bounds here are consistent with the same rigidity for G, but no such theorem for G is claimed.

## What was tried

CEGAR SAT in bases 2 and 3 up to 11 states (all UNSAT), and a complete pure-Python search to 6 states in base 2 and 4 states in base 3. Other bases and larger k were not run. The orbit question itself is untouched.
