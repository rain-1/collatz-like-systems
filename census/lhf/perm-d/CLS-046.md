# CLS-046 [perm_d_s3] - low-hanging-fruit pass (key perm-d)

**Map.** D: 2q -> 5q; 8q+1 -> 5q+1; 8q+3 -> 5q+2; 8q+5 -> 5q+3; 8q+7 -> 5q+4.
Equivalently D(n) = (5n+s)/2^e with the five "letters"

| letter | domain | s | e |
|---|---|---|---|
| E | n = 0 mod 2 | 0 | 1 |
| O_3 | n = 1 mod 8 | 3 | 3 |
| O_1 | n = 3 mod 8 | 1 | 3 |
| O_-1 | n = 5 mod 8 | -1 | 3 |
| O_-3 | n = 7 mod 8 | -3 | 3 |

D is a bijection of Z (and of Z_{>0}); the inverse is 5q -> 2q, 5q+r -> 8q+2r-1.

**Question (GLOBAL).** Is every positive orbit eventually periodic (equivalently, since D is a bijection, is every orbit a finite cycle)? The expected answer is no.

**Status: PARTIAL.** GLOBAL is still open. Two results are proved here:

1. **Obstruction theorem (proved, all moduli).** No congruence certificate exists at any modulus, in either time direction. For every M >= 1 and all residues c, d mod M there are n > 0 with n = c (mod M) and k >= 1 with D^k(n) = d (mod M). So the only forward-invariant unions of residue classes (restricted to Z_{>0}), under D or under D^{-1}, are the empty set and Z_{>0}. This rules out, for every seed and every modulus, the route (a) certificates of the form "the orbit enters a forward-closed union of classes that misses the seed", including trapping neighbourhoods of 2-adic or 5-adic attracting points (these are residue classes) and their backward-orbit analogues. The trap that works for the perturbed map swD_s3 (round2/downfrom5) cannot exist for D itself. This extends the referee's computation for M <= 200 to all M.
2. **No affine self-similar class (proved).** There is no class C = c + N Z_{>0} and k >= 1 such that D^k is a single affine map on C with D^k(C) contained in C. So the "strictly increasing affine subsequence" certificate does not exist.
3. **Short cycles classified (proved, finite computation).** Every cycle of D of length <= 11 is one of {1}, {2,5,3}, {6,15,9} and {26,65,41}.

Seed survey (evidence only): for n <= 20000 and 3000 steps, the only starts that return are the 10 points of these four cycles.

## Proof of 1

Write M = 2^a 5^b m' with gcd(m', 10) = 1.

**Itinerary classes.** For a word w = l_1...l_k in the letters, let C_w be the set of integers whose first k branches are l_1,...,l_k. Each letter is an affine bijection from its domain class onto a class mod 5 (E: 2Z -> 5Z; O_s: r+8Z -> (5r+s)/8 + 5Z). By induction on k, C_w is a single nonempty residue class n_w + 2^{e_w} Z, where e_w is the sum of the letters' e. Indeed C_{l w'} = {n = r + 2^e u : D(n) = D(r) + 5u is in C_{w'}}, and 5 is invertible mod 2^{e_{w'}}. On C_w,

  D^k(n_w + 2^{e_w} t) = D^k(n_w) + 5^k t.     (*)

**Lemma A (the m' part is transitive).** Mod m', each letter acts as an invertible affine map: E(y) = (5/2)y and O_s(y) = (5y+s)/8. This works because 2 and 5 are units mod m', and n = y (mod m') with n in the letter's domain gives D(n) = letter(y) (mod m'). The semigroup G generated by these five permutations of Z/m' is a group, since it is a finite semigroup of permutations. It contains O_3 o O_1^{-1}(z) = (8z - 1 + 3)/8 = z + 1/4, a translation by a unit, so G is transitive on Z/m'. Every element of G is the action A_g of some nonempty word g. (Composition convention: A_{l_1...l_k} = l_k o ... o l_1.)

**Lemma B (the 5^b part is set by the last b letters).** Let |s| = b. By (*), D^b(C_s) is a single class mod 5^b; call its residue F(s). The 5^b sets C_s with |s| = b partition Z, and D^b is a bijection of Z, so the 5^b classes D^b(C_s) partition Z. Hence s -> F(s) is a bijection from words of length b onto Z/5^b. If w = u s with |s| = b, then D^{|w|}(C_w) is contained in D^b(C_s), so D^{|w|}(n) = F(s) (mod 5^b) for every n in C_w.

**Construction.** Let c = (x mod 2^a, y mod 5^b, z mod m') and d = (x', y', z').
- *Prefix p.* Take any n_0 = x (mod 2^a) and let p be its itinerary, long enough that e_p >= a and |p| >= 1. Then C_p is a class mod 2^{e_p} that contains n_0, so C_p is contained in x + 2^a Z. The same holds for C_w whenever w starts with p.
- *Suffix s.* By Lemma B, pick s with |s| = b and F(s) = y'. If b = 0, s is empty.
- *Middle g.* Let z_1 = A_p(z). By Lemma A, pick g with A_g(z_1) = A_s^{-1}(z'). This is possible because A_s is in the group G.
- Let w = p g s and k = |w| >= 1. Take n = n_w + 2^{e_w} t, where t is chosen so that n = y (mod 5^b) and n = z (mod m'). This is a single condition on t mod 5^b m', solvable because 2^{e_w} is a unit there. Take t large, so n > 0.

Then n = x (mod 2^a) by the prefix, and n = y (mod 5^b) and n = z (mod m') by the choice of t, so n = c (mod M). For the image: D^k(n) = A_w(z) = A_s(A_g(A_p z)) = z' (mod m') and D^k(n) = F(s) = y' (mod 5^b). By (*), D^k(n) = D^k(n_w) + 5^k t. Here t is constrained only mod 5^b m', which is coprime to 2^a, so we can also choose t mod 2^a (CRT) to make D^k(n) = x' (mod 2^a). Hence D^k(n) = d (mod M), with n > 0, and D maps Z_{>0} to itself.

**Consequences.** Let A be a nonempty union of classes mod M, intersected with Z_{>0}, with D(A) contained in A. Take a class c in A and any class d. Some n in c reaches d, so d meets A. Each class mod M lies either wholly inside A or wholly outside it, so d lies in A, and A = Z_{>0}. For D^{-1}: if D^{-1}(B) is contained in B, then the complement of B is D-forward-invariant (D is a bijection), so B is empty or everything. A congruence certificate of an infinite orbit is an invariant union of classes that misses the seed but meets the orbit, in either time direction, so none exists. QED.

## Proof of 2

Suppose D^k(n) = (5^k n + beta)/2^e on C = c + N Z_{>0} (with e >= k >= 1) and D^k(C) is contained in C. Then D^k(c + N t) = D^k(c) + (5^k N / 2^e) t. For this to lie in c + N Z for t = 0 and t = 1, N must divide 5^k N / 2^e, so 2^e divides 5^k. That is impossible. QED.

(This also follows from part 1 applied to the D-forward closure of C, but the direct argument is shorter.)

## Proof of 3

A cycle of length k through n has some itinerary w of length k, and D^k(m) = (5^k m + beta_w)/2^{e_w} on C_w. Then n = beta_w/(2^{e_w} - 5^k), and the denominator is never 0. The check enumerates all 5 + 5^2 + ... + 5^11 words, keeps every positive integer candidate whose simulated itinerary is w and which returns to itself, and finds exactly the four cycles listed. This is exact integer arithmetic.

## What this says about the problem

Route (a) is closed in its congruence form for every modulus and both directions, by a uniform argument rather than search. The 2-adic part of D is a full one-sided shift (every itinerary is realised by a class), the coprime part is a transitive affine group, and the 5-adic part is a function of the recent itinerary. Together these make every residue graph strongly connected. Any proof that some orbit is infinite must therefore use a non-congruence invariant (for example a non-periodic automatic set, or an archimedean argument). The heuristic drift is (1/2) log(25/16) > 0, so infinite orbits are still expected. No such certificate was found. GLOBAL remains of the same type as Collatz's 1932 problem (orbit of 8 under 2n/3, round(4n/3)), and it is not known to be equivalent to it.

- The letters: (5(8q+r)+s)/8 gives 5q+1, 5q+2, 5q+3, 5q+4 for (r,s) = (1,3), (3,1), (5,-1), (7,-3). D is a bijection of Z with the stated inverse.

Inverses are positive powers in a finite permutation group, so every element is a nonempty word. Correct.
- Lemma B: D^b(C_s) = D^b(n_s) + 5^b Z is a full class mod 5^b. D^b is a bijection of Z, so these 5^b images are disjoint, and s -> F(s) is a bijection. Correct.
