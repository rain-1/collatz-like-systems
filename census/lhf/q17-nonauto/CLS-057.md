# CLS-057 [qrA3_q17]: independent verification of nonautomaticity in every base

**Map.** T(n) = n/2 for even n, and T(n) = (n + 17c)/3 for odd n, where c = n mod 3.
**Question (BASIN, strong form).** Is there a finite-state rule deciding whether n reaches (1 6 3) or (5 13 10), or a proof that none exists?

**Status: PROVED (no finite automaton exists in any integer base k >= 2).**

## Theorem
For every k >= 2, no DFA reading base-k digits separates B_1 (the basin of 1) from B_5 (the basin of 5) on inputs coprime to 17.

## Proof outline, with each step re-checked
Let f(n) = 1 if n is in B_5 and f(n) = 0 otherwise.

1. **Descent and cycles.** For n > 17, T(n) <= (n+34)/3 < n. The interval [1,17] is invariant, and its only cycles are (1 6 3), (5 13 10) and (17). Each branch satisfies m*T(n) = n mod 17 with m in {2,3}, so B_17 = 17N.
2. **Dilation invariance: f(2n) = f(3n) = f(n) for all n.** T(2n) = n. If n = 2^s u with u odd, then 3u is odd with 3u = 0 mod 3, so T(3u) = u.
3. **Lemma rough.** Let gcd(Q,6) = 1 and b, c be in {1,5}. Then B_b contains arbitrarily large odd z with z = c mod Q. The inverse branches L(y) = 3y and R(y) = 3y - 34 both map back to y under T for odd y; I checked the residues: 3y - 34 = 2 mod 3, so c = 2 and (3y-34+34)/3 = y. Both inverses permute Z/Q, so the semigroup they generate is a group and contains RL^{-1} = translation by -34. Since Q is odd, gcd(34,Q) is 1 or 17. When it is 17, L connects 1 and 5 because 3^5 = 5 mod 17. Start the word at 3^h b, with h a large multiple of ord_Q(3), so that every intermediate value is positive and odd.
4. **Lemma lift.** Reverse a path x -> c whose branch-denominator product is A. Then x + A(y - c) follows the same branches to y, for every y >= c with y = c mod 2. An even displacement keeps the parity, and a displacement of 3h keeps the residue mod 3, so each branch digit is preserved.
5. **Theorem mix.** If 17 does not divide x, the class x mod M contains arbitrarily large members of both B_1 and B_5. One reverse lap of either cycle has denominator product 2·3·3 = 18; I checked it on both cycles (1->6->3->1: 3,2,3; 5->13->10->5: 3,3,2). Write M = 2^u 3^v Q. Take y = c + 18^t (z - c) with t >= u and 2t >= v, then lift. Consequence: f restricted to any progression Dn + r that contains a unit mod 17 is not ultimately periodic.
6. **Kernel theorem.** Suppose h is k-automatic, h(pn) = h(n), and p and k are multiplicatively independent. Let S be the set of k-kernel members that have a representation h(k^a n + r) whose progression contains a unit mod ℓ, where ℓ = 17 does not divide p. Then every base-p digit word can be read through S from some state. To see this, take r = -Dd mod p^e, or that value plus p^e, choosing the one not divisible by 17. Then r_j = (D d_j + r)/p^j lies in [0, D). If 17 divides D, then 17 does not divide r_j, because p^j r_j = r mod 17. The elimination argument then gives a single state of S that reads every word. That state's whole p-kernel lies in the finite set S, so it is both p-automatic and k-automatic. By Cobham's theorem it is ultimately periodic, which contradicts step 5.
7. **Choice of p.** Take p = 2 if k is not a power of 2, and p = 3 otherwise.

Every step holds as written. I found no gap. Two points need care, and both are handled correctly. First, S is nonempty: h itself has a = 0 and r = 0. Second, the r_j stay below D, which holds because D > 2p^e > r.

## Computational part (`check_CLS-057.py`, about 1 s, exit 0)
The script is self-contained and does not import `qrlib`. It checks:
- the table on [1,17], the three cycles, and descent and the 17-divisibility equivalence for n < 2·10^5;
- f(2n) = f(n) and f(3n) = f(n) up to 2^20;
- the inverse branches L and R and the reverse lap of multiplier 18;
- **constructive witnesses**: 2124 cases, covering 18 moduli M (including 289, 4913, 2448 and 1001), x coprime to 17, and both target basins. For each case it builds the explicit integer from Lemmas rough and lift and Theorem mix, then confirms by forward iteration that it is congruent to x mod M and lies in the requested basin;
- the section identity f(D(p^j n + d_j) + r) = f(Dn + r_j) for all 4-digit words in bases (k,p) = (2,3), (3,2), (6,2), (10,2), (17,2), (34,2) and (4,3).

**Corrected claim.** For every integer k >= 2, the indicator of B_5 (with 0 on multiples of 17) is not k-automatic. Equivalently, no base-k DFA, reading MSD-first or LSD-first, separates the basins of (1 6 3) and (5 13 10) on inputs coprime to 17. This settles the strong-form BASIN question negatively for integer bases. Non-integer numeration systems and weaker notions such as k-regularity are not covered.

**What I re-derived independently.**
- Branches: n + 17c = 0 mod 3 forces c = n mod 3, which matches qrlib.famA. Descent holds for n > 17. The table on [1,17] gives the cycles 1, 5 and 17, and m*T(n) = n mod 17 gives B_17 = 17N.
- Dilations: f(2n) = f(n), and f(3n) = f(n) because T(3u) = u for odd u.
- Lemma rough: L and R are odd-preserving inverse branches. 3y - 34 = 2 mod 3, so R is a genuine inverse. In the finite permutation semigroup, RL^{-1} is translation by -34. The case 17 | Q uses 3^5 = 5 mod 17. Positivity comes from the 3^h b prefix.
- Lemma lift: with an even displacement h, the predecessor shifts by 2h or 3h, so parity and the residue mod 3 are preserved. Both laps have A = 18 (1->6->3->1 has denominators 3, 2, 3; 5->13->10->5 has 3, 3, 2). This gives y = c mod 2^u 3^v Q.
- Kernel theorem: r_j is integral because d = d_j mod p^j. The bound r_j < D follows from r < 2p^e < D. If 17 | D, then 17 does not divide r_j, since p^j r_j = r mod 17. The elimination argument is sound: the set of surviving starts strictly shrinks, and S is finite and nonempty. A state that reads every word has a finite p-kernel. Cobham's theorem for finite-valued sequences then makes it ultimately periodic, which contradicts the corollary. The choice p in {2,3} is multiplicatively independent of k.
- I found no hidden conjecture and no step that relies on simulation. The finite computations, the [1,17] table and the 3^5 identity, are exhaustive.

**One precondition the reader should keep explicit.** Theorem mix needs z >= c. Lemma rough provides arbitrarily large z, so this is satisfied. My first harness version skipped it: with Q = 1 it produced z = 3 < c = 5, and the lift went wrong. That was a bug in my harness, not a gap in the proof.
