# CLS-057 (qrA3_q17): finite-state basin rule

**Map.** n even -> n/2; n odd -> (n + 17c)/3 with c = n mod 3.
**Question (strong form).** Give a finite-state rule deciding whether n reaches (1 6 3) or
(5 13 10), or prove that none exists.

**Status: PROVED (none exists, in any integer base).** The proof was already in the repository
(commit 36553ef, `census/round2/qr/qrA3_q17.md`, `output/tex/nonautomatic_basins_q17.tex`).
**ID note.** This sweep originally used a temporary numbering. All identifiers in census/lhf have been translated to the numbering of census/open_collatz_systems.txt, where this item is CLS-057 (map: census/lhf/id_map_sweep_to_catalog.json).

## What this lane did
1. **Independent audit of the proof.** I re-derived every step, and found no gap:
   * The reverse path from a unit x to its cycle point c is the affine map y -> x + A(y-c).
     The parity of each intermediate value is preserved when y = c (mod 2), because
     3y - 17d = d (mod 3) recovers the branch digit. Every intermediate value is >= its
     forward value when y >= c.
   * L(y)=3y and R(y)=3y-34 are odd predecessors (T(3y) = T(3y-34) = y for odd y; for R,
     -34 = 2 (mod 3)). Mod Q (coprime to 6) they generate a group containing y -> y-34. If 17 | Q,
     the factor 3^5 = 5 (mod 17) joins the residues 1 and 5.
   * Reversing t laps gives c + 18^t (z-c). So both basins meet every progression x + MN in
     arbitrarily large elements. Therefore no section f(Dn+r) whose progression contains a unit
     mod 17 is ultimately periodic.
   * Kernel step: D(p^j n + d_j) + r = p^j (D n + r_j), and f(p^j m) = f(m) for p in {2,3}.
     So the partial base-p transitions stay inside the finite k-kernel. A state that reads every
     word exists by the standard elimination argument. Then Cobham (k and p multiplicatively
     independent) gives an ultimately periodic member of S, which is a contradiction. The choice
     p = 3 when k is a power of 2, and p = 2 otherwise, covers every k >= 2 (including 6, 12, 18).
2. **Constructive re-verification** (`check_CLS-057.py`). The script is written from scratch and
   does not reuse `qrlib`. It runs the progression lemma as an algorithm for 14 moduli M
   (including 17, 289, 2^5·3^3·17, 4·17·23, 1001), 12 random units x < 10^6 and both targets
   b in {1,5}. Each of the 322 cases builds x' = x (mod M), x' > 10^6, and confirms
   basin(x') = b by forward iteration. The script also checks descent, the table,
   basin(2n) = basin(3n) = basin(n) and 17|n <=> basin 17 for n <= 3·10^5, and the section
   identity in bases 2, 3, 4, 6, 10, 12, 18. Exit 0, run time about 0.4 s. The original check
   `census/round2/qr/check_qrA3_q17.py` also passes again (exit 0).

## Consequence for the assigned approach
The suggested search for an invariant F with F(T(n)) = F(n), computable by a finite transducer
in base 2, 3, 6, 12 or 18, **provably cannot succeed**. Such an F that agrees with the finite
table would make the basin k-automatic, which the theorem excludes for every integer base k.
So I did not run that search. Any exact description of the basin must therefore be
non-automatic: for example, a description in terms of branch words (parity vectors), which
needs unbounded memory in both the 2-adic and the 3-adic direction. Whether the basin sequence
is *morphic* (a non-uniform substitution) is a different and weaker question. The factor
complexity (w+2)·2^(w-1) for w <= 7 grows superlinearly and does not settle it either way. I
made no progress on that variant, and it is not the question CLS-057 asks.

## Referee
**Verdict: CONFIRMED. It is not a new result.** The theorem and its proof are already in the
notes file `census/round2/qr/qrA3_q17.md` (commit 36553ef), (CLS-057). This lane contributes an audit and a second
check script, not a new theorem. The CLS-057 status line in the sweep's temporary list was stale; census/open_collatz_systems.txt already points to the proof.

I re-derived each step independently:
* f(2n) = f(n) holds because T(2n) = n. f(3n) = f(n) holds for all n: for odd n, T(3n) = n with
  c = 0, and even n reduces to odd n by halving.
* Reverse path. Each reverse odd step 3y' - 17d is congruent to d mod 3, since -17 = 1 mod 3. Its
  parity equals the parity of y' + d. Before any halving, y' - w' = 3^i (y - c). So the condition
  y = c (mod 2) keeps every intermediate value at the right parity, and y >= c keeps them
  positive. One lap from 1 or from 5 has denominators 3, 2 and 3, so reversing one lap is
  z -> c + 18(z - c).
* L(y) = 3y and R(y) = 3y - 34 are odd predecessors of an odd y (-34 = 2 mod 3). Modulo Q coprime
  to 6 they are permutations, so the semigroup they generate is a group and contains y -> y - 34.
  Then gcd(34, Q) is 1 or 17. In the second case, 3^5 = 5 (mod 17) connects 1 and 5. For y > 17
  both maps increase y, so the values stay positive.
* Choosing t with 2^u 3^v | 18^t gives M | A * 18^t (z - c). This proves the progression lemma, and
  ultimate periodicity of any section that contains a unit fails.
* Kernel step. D d_j + r = D(d_j - d) = 0 (mod p^j). The bound r_j < D holds because r < D and
  d_j < p^j. The unit condition holds because p^j r_j = r (mod 17) when 17 | D. The
  elimination argument, which builds one word unreadable from every state, is correct. The pair
  p = 2 / p = 3 is multiplicatively independent of k exactly as stated. Cobham (1969) then
  applies to the 0/1 sequence g. Nothing depends on an open conjecture. The only external
  inputs are the kernel characterization (Allouche-Shallit) and Cobham's theorem, both
  standard.
* The reduction from "classifier on units" to "automaton for f" is sound, because n mod 17 is
  computable by an automaton in either reading direction.

Small qualifications:
1. The phrase "no transducer-computable invariant F" needs the hypothesis that F separates the
   two cycles. The argument then runs as follows: the preimage of the regular set {F(1)} under a
   rational function is regular, and intersecting it with the units gives the basin of 1.
2. The check scripts only illustrate the constructive lemma and the section identity, the latter
   for small n. The proof is the written argument, and the checks do not substitute for it.
