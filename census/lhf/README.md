## What collapsed

* **3n+d (`collatz3/`).** GLOBAL for 6n+2, 3n+1, 3n+3 and 3n+9 is exactly the
  Collatz no-divergence statement P1, and 3n-1 is the same statement on the
  negative integers. For gcd(d,6)=1, GLOBAL(3n+d) holds if and only if P1 holds
  and no positive rational whose denominator divides d has a divergent 3x+1
  orbit. Every cycle with one local minimum is listed. That part rests on a
  cited Ellison/Rhin bound for |2^K-3^k|, which was quoted but not re-proved.
* **5n+d (`five/`).** Every entry reduces to 5x+1 statements by scaling (for
  example 5n+5 on 5Z is 5x+1) or by an orbit embedding (10n+2).
* **The 1932 map (`perm-near/`, `perm-swap-c/`).** CLS-041, 042, 043, 044 and 054
  are rigorously equivalent to CLS-039 or CLS-040, the orbit of 8 and the global
  question.

## Proved obstructions

These hold at every modulus, not only up to a search bound:

* 7n+1, 9n+1 and m3_e (`seven-nine/`): every nonempty forward-closed union of
  residue classes contains 1, so no congruence trap can prove an orbit
  divergent. For 9n+1 this means a trap would have to prove the orbit of 1
  unbounded.
* perm_swap: the only closed unions of residue classes are the empty set,
  everything, 5Z and its complement.
* perm_d, and the 1932 map in both directions: the residue graphs are strongly
  connected. This is a complete written proof of the earlier sketch.
* swT9 (CLS-055): the residue graph is strongly connected for every modulus
  not divisible by 3, which rules out congruence traps at those moduli.

## Restricted cycle results

* 9n+1 has no cycle with at most 1000 odd terms.
* 7n+1: the only such cycle is {1,8,4,2}.
* m3_e: the only cycles with at most 1000 non-multiples of 3 are {1,9,3} and a
  14-cycle through 4.
* One-local-minimum cycle classifications, via Laurent-Mignotte-Nesterenko:
  * split5_1 (CLS-048): only {1,3}.
  * desc_split7_1 (CLS-053) and desc_s32_plus9 (CLS-052): none.
  * desc_m3_4n5 (CLS-051): only (16 69 23 48).

  The LMN constant was quoted from memory and should be checked against the paper.
* yah_avoid57 (CLS-056): possible counterexamples up to X number O(X^0.406).

## New theorem (`q17-family/CLS-057.md`)

**Theorem F.** Let m >= 3 be odd and gcd(q,2m) = 1. Define T(n) = n/2 for even n
and T(n) = (n+cq)/m for odd n. If some coset of <2,m> in (Z/q)^* contains two
or more cycles, then for every base k >= 2 no basin of a cycle in that coset is
k-automatic.
