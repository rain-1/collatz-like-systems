# CLS-052 desc_s32_plus9: cycles with one expanding run

**Map.** T: even n -> n/2; odd n -> 3n+1 if n mod 32 ∈ R = {1,3,5,7,9,11,13,15,17,21,23,25,29}, else n+1 (n ≡ 19, 27, 31 mod 32).
**Question.** GLOBAL. This note does not settle it.

**Status: PARTIAL (PROVED restricted result).**

## Result
S is the odd-to-odd map: S(n) = (3n+1)/2^v if n mod 32 ∈ R, and S(n) = (n+1)/2^v otherwise. S(n) > n holds exactly when n ≡ 3 (mod 4) and n mod 32 ∈ R, where S(n) = A(n) = (3n+1)/2.

**Theorem.** The only cycle of S without expanding steps is the fixed point 1, which is the T-cycle (1 4 2). S has **no** cycle with exactly one expanding run. Every further cycle therefore has at least two separate runs of (3n+1)/2-steps. Below 10^5 the only cycle is {1}; that is evidence only.

## Proof
**Step facts.**
- A(n) + 1 = (3/2)(n+1), and A needs 4 | n+1.
- A non-A step is either (3n+1)/2^v with v ≥ 2 (when n ≡ 1 mod 4), with ratio ≤ 3/4 + 1/(4n), or (n+1)/2^v with v ≥ 2 (classes 19 and 27 have v = 2, class 31 has v ≥ 5), with ratio ≤ (n+1)/(4n). Equality S(n) = n holds only at n = 1.

**(1)** For a run of length k from the minimum n_0, v_2(n_0+1) ≥ k+1. So n_0 ≥ 2^{k+1}−1 ≥ 3.

**(2)** For n ≥ 3 every non-A ratio is ≤ 5/6, and y ≤ (4/3)(3/2)^k n_0. So j ≤ 2.2240k + 1.5779, and the total count of 3-steps is J ≤ 3.2240k + 1.5779.

**(3)** With K the total 2-exponent,
 0 < Λ := K log 2 − J log 3 ≤ (J/3 + j_B)/n_0 ≤ (k/3 + j)/n_0 ≤ (2.558k + 1.578)/n_0.

**(4) LMN 1995, Cor. 2.** Take α_1 = 2 and α_2 = 3, with b' = K/log 3 + J. This gives F(17100) = 50.4 > 0, and F is increasing beyond that point, so k < 17100 and J ≤ 55128.

**(5) Finite part.** For each J ≤ 55128, let K be minimal with 2^K > 3^J and set d = 2^K − 3^J. A cycle requires (2^{k+1}−1)·d ≤ (2.558k+1.578)·2^K for some admissible k. Fourteen values of J survive, and they give n_0 ≤ 1191. A direct search over all odd n_0 ≤ 1191 finds no one-run cycle. ∎

## Scope
The 2-adic 12-cycle through −227/115 from round 2 (its odd residues 15, 7, 11 rise and 1, 9 fall) is itself one-run. It is not a positive integer, so the theorem does not exclude it. The theorem shows that no positive integer cycle with that one-run shape exists. Cycles with ≥ 2 runs and GLOBAL remain open.
