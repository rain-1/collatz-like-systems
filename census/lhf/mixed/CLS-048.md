# CLS-048 split5_1: cycles with one expanding run

**Map.** T: even n -> n/2; n ≡ 1 (mod 4) -> 5n+1; n ≡ 3 (mod 4) -> n+1.
**Question.** GLOBAL. This note does not settle it.

**Status: PARTIAL (PROVED restricted result).**

## Result

Let S be the odd-to-odd map: S(n) = A(n) = (5n+1)/2 if n ≡ 1 (mod 4), and S(n) = B(n) = (n+1)/2^{v_2(n+1)} if n ≡ 3 (mod 4).
Cycles of T and cycles of S correspond one to one, because every T-cycle contains odd values.
We call a cycle of S **one-run** if its A-steps form a single cyclic block. Since S(n) > n exactly at the A-steps, these are the cycles with exactly one local minimum.

**Theorem.** The only one-run cycle of S is {1, 3}, which is the T-cycle (1 6 3 4 2). The other known cycle (minimum 13, length 14 under S) has 4 runs.
Also, S has no cycle without A-steps: B(n) ≤ (n+1)/4 < n.

## Proof

**Step facts.**
- For odd n, n ≡ 1 (mod 4) holds iff 4 | 3n+1. Also 3A(n)+1 = (5/2)(3n+1), and A(n) is odd.
- For n ≥ 1, B(n) ≤ (n+1)/4 ≤ n/2.

**(1) A run of length k forces a large start.** Let n_0 be the minimum of a one-run cycle and k ≥ 1 its run length. A minimum is followed by an increase, so the run starts at n_0. The v_2 of 3n_i+1 drops by exactly 1 per A-step and must be ≥ 2 before each A-step. Hence v_2(3n_0+1) ≥ k+1, and so n_0 ≥ (2^{k+1}-1)/3.

**(2) The descent is short.** The run ends at y = A^k(n_0) = (5/2)^k(n_0+1/3) - 1/3 ≤ (4/3)(5/2)^k n_0. Then j B-steps lead back to n_0. Each B-step at least halves the value, so j ≤ log_2(y/n_0) ≤ 1.3220k + 0.4151.

**(3) Linear form.** Step ratios are A: (5/2)(1+1/(5n)) and B: 2^{-v}(1+1/n). Their product around the cycle is 1. Let K be the total 2-exponent. Then

 Λ := K log 2 − k log 5 = Σ_A log(1+1/(5n_i)) + Σ_B log(1+1/n_i).

So 0 < Λ ≤ (k/5 + j)/n_0 ≤ (1.53k + 0.42)/n_0 ≤ 3(1.53k+0.42)/(2^{k+1}−1).

**(4) Baker bound (Laurent–Mignotte–Nesterenko 1995, Cor. 2).** Take α_1 = 2, α_2 = 5, b_1 = K, b_2 = k and D = 1. Then log A_1 = 1 and log A_2 = log 5. Also b' = K/log 5 + k ≤ 2.443k + 0.63, since K ≤ k log_2 5 + 1 when Λ < log 2. The corollary gives

 log Λ ≥ −24.34 · max(log b' + 0.14, 21)^2 · log 5.

Let F(k) be the upper bound from (3) minus this lower bound, in logarithms: F(k) = (k+1) log 2 − log 3 − log(1.53k+0.42) − 24.34 log 5 · max(log(2.443k+0.63)+0.14, 21)^2. Then F(25000) = 42.1 > 0. F is increasing for k ≥ 10^4, because its derivative is at least log 2 − 1/k − 78.4(log(2.5k)+0.14)/k > 0. Hence every one-run cycle has k < 25000.

**(5) Finite part (exact integers).** Fix k < 25000 and let K be minimal with 2^K > 5^k, writing d = 2^K − 5^k. Every admissible K' ≥ K gives Λ ≥ d/2^K, since log x ≥ 1 − 1/x. So a cycle needs ⌊(2^{k+1}−1)/3⌋ · d ≤ (1.53k+0.42) · 2^K. Exactly 6 values of k survive: k = 1..6. For each of them n_0 ≤ (1.53k+0.42)·2^K/d ≤ 213. Checking every odd n_0 ≤ 213 directly finds only n_0 = 1 (k = 1). ∎

## Scope
This settles cycles with one local minimum (of S). Cycles with 2 or more runs remain open: the start-size bound (1) controls only the run that starts at the global minimum. GLOBAL itself remains a 3x+1-type problem.
