# CLS-051 desc_m3_4n5: cycles with one expanding run

**Map.** T: 3|n -> n/3; n ≡ 1 (mod 3) -> 4n+5; n ≡ 2 (mod 3) -> 2n+2.
**Question.** GLOBAL. This note does not settle it.

**Status: PARTIAL (PROVED restricted result).**

## Result
Let S act on the non-multiples of 3 by S(n) = (4n+5)/3^v if n ≡ 1 (mod 3) and S(n) = (2n+2)/3^v if n ≡ 2 (mod 3), where v is the full 3-adic valuation. T-cycles and S-cycles correspond one to one. S(n) > n holds exactly when n ≡ 1 (mod 3) and 9 ∤ 4n+5, where S(n) = A(n) = (4n+5)/3.

**Theorem.** The cycles of S without expanding steps are the fixed points 1 and 2, which are the T-cycles (1 9 3) and (2 6). The **only** cycle of S with exactly one expanding run (one local minimum) is {16, 23}, which is the T-cycle (16 69 23 48).

## Proof
**Step facts.**
- A(n) + 5 = (4/3)(n+5), and A applies only if 3 | n+5.
- The non-A steps are C(n) = (4n+5)/3^v with v ≥ 2, with ratio ≤ 4/9 + 5/(9n), and E(n) = (2n+2)/3^v with v ≥ 1, with ratio ≤ 2/3 + 2/(3n).
- Non-A steps satisfy S(n) ≤ n, with equality only at n = 1, 2. So a cycle without A-steps is {1} or {2}, and in every other cycle the non-A steps strictly decrease.

**(1)** Let the cycle have minimum n_0 and one run of length k. Then n_0 ≡ 1 (mod 3) and n_0 ≠ 1, so n_0 ≥ 4. Also 3 | n_i + 5 for i < k, and v_3 drops by 1 per A-step, so v_3(n_0+5) ≥ k. Hence n_0 ≥ max(4, 3^k − 5).

**(2)** For n ≥ 4 every non-A ratio is ≤ 5/6. Also y = A^k(n_0) ≤ (9/4)(4/3)^k n_0. So the descent has j ≤ 1.5779k + 4.448 steps.

**(3)** The ratios are (4/3^v)(1+5/(4n)) and (2/3^v)(1+1/n). Let K be the total 3-exponent and L = 2(k + j_C) + j_E ≤ 5.1558k + 8.897 the total 2-exponent. Then
 0 < Λ := K log 3 − L log 2 ≤ 1.25(k+j)/n_0 ≤ (3.2225k + 5.561)/n_0.

**(4) LMN 1995, Cor. 2.** Take α_1 = 2 and α_2 = 3, with log A_1 = 1 and log A_2 = log 3. Here b' = L/log 3 + K. This gives F(10800) = 62.1 > 0, and F is increasing beyond that point, so k < 10800 and L ≤ 55686.

**(5) Finite part.** For each L ≤ 55686, let K be minimal with 3^K > 2^L and set d = 3^K − 2^L. A cycle requires max(4, 3^k−5)·d ≤ (3.2225k+5.561)·3^K for some admissible k, meaning 2k ≤ L ≤ 5.1558k + 8.897. The ratio (3.2225k+5.561)/(3^k−5) decreases for k ≥ 2, so it suffices to test the smallest two admissible k. Twenty-six values of L survive, all with L ≤ 38, and they give n_0 ≤ 2567. A direct search over all n_0 ≤ 2567 finds only n_0 = 16 (k = 1). ∎
