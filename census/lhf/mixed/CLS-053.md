# CLS-053 desc_split7_1: cycles with one expanding run

**Map.** T: even n -> n/2; n ≡ 1 (mod 4) -> 7n+1; n ≡ 3 (mod 4) -> n+1.
**Question.** GLOBAL. This note does not settle it.

**Status: PARTIAL (PROVED restricted result).**

## Result
S is the odd-to-odd map: S(n) = (7n+1)/2^v if n ≡ 1 (mod 4), and (n+1)/2^v if n ≡ 3 (mod 4), with v = the full 2-adic valuation in each case. T-cycles and S-cycles correspond one to one. S(n) > n holds exactly when n ≡ 5 (mod 8), where S(n) = A(n) = (7n+1)/4.

**Theorem.** S has **no** cycle with exactly one expanding run (one local minimum). The only cycle of S without expanding steps is the fixed point 1, which is the T-cycle (1 8 4 2). So every further cycle has at least two separate runs of A-steps.

## Proof
**Step facts** (all exact).
- For odd n, n ≡ 5 (mod 8) holds iff 8 | 3n+1, and then 3A(n)+1 = (7/4)(3n+1).
- A non-A step is either C(n) = (7n+1)/2^v with v ≥ 3 (n ≡ 1 mod 8), with ratio ≤ 7/8 + 1/(8n), or B(n) = (n+1)/2^v with v ≥ 2, with ratio ≤ (n+1)/(4n).
- C(n) = n only for n = 1, and B(n) < n always. So a cycle without A-steps is {1}.

**(1)** Let the cycle have minimum n_0 and one run of k ≥ 1 A-steps, starting at n_0. The 2-adic valuation v_2(3n+1) drops by 2 per A-step and must be ≥ 3 before each A-step. So v_2(3n_0+1) ≥ 2k+1, which gives n_0 ≥ (2^{2k+1}−1)/3 ≥ 5.

**(2)** For values ≥ 5 every non-A step has ratio ≤ 0.9. Also y = A^k(n_0) ≤ (16/15)(7/4)^k n_0. So the descent has j ≤ (k log(7/4) + log(16/15))/log(10/9) ≤ 5.3116k + 0.6126 steps. The total number of 7-steps is J = k + j_C ≤ 6.3116k + 0.6126.

**(3)** The step ratios are 7·2^{-v}(1+1/(7n)) and 2^{-v}(1+1/n). With K the total 2-exponent,
 0 < Λ := K log 2 − J log 7 ≤ (J/7 + j_B)/n_0 ≤ (k/7 + j)/n_0 ≤ (5.455k+0.613)/n_0.

**(4) LMN 1995, Cor. 2.** Take α_1 = 2 and α_2 = 7, so log A_1 = 1 and log A_2 = log 7. Here b' = K/log 7 + J ≤ 2.443J + 0.52. Then
F(k) = (2k+1) log 2 − log 3 − log(5.455k+0.613) − 24.34 log 7 · max(log b'(k) + 0.14, 21)^2
satisfies F(15100) = 34.0 > 0, and F is increasing for k ≥ 10^4. Hence k < 15100, and so J ≤ 95299.

**(5) Finite part.** For each J ≤ 95299, let K be minimal with 2^K > 7^J and set d = 2^K − 7^J. Then Λ ≥ d/2^K. A cycle requires ⌊(2^{2k+1}−1)/3⌋·d ≤ (5.455k+0.613)·2^K for some k with (J−0.6126)/6.3116 ≤ k ≤ J. The left side over the right side is increasing in k, so it suffices to test the smallest two admissible k. Twenty values of J survive, all with J ≤ 26, and they give n_0 ≤ 23498. A direct test of every odd n_0 ≤ 23498 finds no one-run cycle. ∎
