# CLS-066 (up_ct3): Collatz with the trapdoor 7 mod 8

**Map.** n = 7 mod 8 -> n+8 (trap). Otherwise T(n) = n/2 for even n and (3n+1)/2 for odd n.

**Question.** Which n have infinite (unbounded) orbits? Is the set exactly the trap basin, with (1 2) the only untrapped cycle?

**Status: PARTIAL (PROVED results below; the question itself stays open).**

The question is now known to be *exactly* Yolcu-Aaronson-Heule Conjecture 4.13, one of their $500 prize problems. It implies CLS-056. In addition, every n outside an explicit set of size O(X^0.8792) is trapped, with a proof.

## Theorem 1 (exact equivalence)
The up_ct3 question has answer "yes" (divergent set = trap basin, and (1 2) is the only untrapped cycle) iff

> **YAH Conjecture 4.13** (arXiv:2105.14697 v3, Sec. 4.5): every Collatz C-trajectory (C(n) = n/2 or 3n+1) of a positive integer that does not reach 1 contains some m = 7 (mod 8).

*Proof.* Before an up_ct3 orbit is trapped, it coincides with the T-orbit. Trapped orbits increase by 8 forever, so they are unbounded. Hence the answer is "yes" iff every T-orbit that never meets 7 mod 8 reaches 1. The reason: an untrapped orbit either reaches 1 and enters (1 2), or is unbounded, or is bounded and so eventually periodic in a cycle other than (1 2). The T-trajectory and the C-trajectory of n contain the same odd numbers. T(n) = (3n+1)/2 for odd n only skips the even value 3n+1, and halvings agree. Every m = 7 mod 8 is odd. So "the T-trajectory meets 7 mod 8" is the same as "the C-trajectory meets 7 mod 8". Likewise the T-trajectory reaches 1 iff the C-trajectory does. The right-hand side is therefore Conj. 4.13 word for word. ∎

**Corollary.** CLS-066 = yes implies CLS-056 = yes (YAH Conj. 4.14), because avoiding {5,7} implies avoiding 7. So CLS-066 is the stronger problem of the two. It is a stated $500 prize problem, which is evidence that it is not low-hanging. YAH report that their SAT/matrix-interpretation search failed on it.

## Theorem 2 (density: all but O(X^0.8792) integers are trapped)
Let U = {n >= 1 : the up_ct3 orbit of n is never trapped}. For X >= 2,

    #(U ∩ [1,X]) <= 2 t_L <= 4 X^{log2 τ},   with L = floor(log2 X) and log2 τ = 0.87915...

Here τ = 1.839286... is the tribonacci constant (τ^3 = τ^2+τ+1), and t_L is the number of binary words of length L with no factor 111.

As a consequence, the divergent set D satisfies

    Trap basin ⊆ D ⊆ Trap basin ∪ (U \ {n reaching 1}),

and the trap basin contains the explicit union R_L of residue classes mod 2^L whose T-parity word of length L contains 111. R_L has density 1 - t_L/2^L -> 1.

*Proof.* Let v_i(n) = T^i(n) mod 2. **(Terras)** The map n mod 2^L -> (v_0..v_{L-1}) is a well-defined bijection Z/2^L -> {0,1}^L. By induction, T^i(n + 2^L k) = T^i(n) + 3^{#ones} 2^{L-i} k. Applied with L = 3 to m = T^i(n), it gives T^i(n) = 7 mod 8 iff v_i v_{i+1} v_{i+2} = 111. The classes mod 8 correspond to words as follows: 1->101, 3->110, 5->100, 7->111 (and even classes start with 0). So if n ∈ U, the word v_0..v_{L-1} has no factor 111, and n lies in one of t_L residue classes mod 2^L. Since 2^L <= X < 2^{L+1}, each class has at most 2 members in [1,X]. Hence the count is at most 2 t_L. Next, t_0, t_1, t_2 = 1, 2, 4, and t_L = t_{L-1}+t_{L-2}+t_{L-3}: a word is w0, w01 or w011 with w free. The bound t_L <= 2τ^L holds for L <= 2 by direct check and follows by induction from τ^L = τ^{L-1}+τ^{L-2}+τ^{L-3}. Finally τ^L = 2^{L log2 τ} <= X^{log2 τ}. ∎

Remarks.
- Empirically #(U ∩ [1,2^k]) grows like 1.64^k (≈ X^0.71). U contains the whole backward tree of 1 inside the 111-free shift, so the exponent cannot drop below the growth exponent of that tree. The bound is honest but not sharp.
- The bound holds for the per-n statement "n is trapped or reaches 1" with the same exceptional count. Combined with Barina's verification (2^68), every exception is either > 2^68 or reaches 1.

## Referee
**Verdict: CONFIRMED (status PARTIAL; the question stays open, and is exactly a named prize conjecture).**
- Theorem 1 re-derived. An untrapped up_ct3 orbit is the T-orbit, and a trapped one goes to infinity. So "divergent set = trap basin and (1 2) is the only untrapped cycle" fails iff some T-orbit avoids 7 mod 8 and never reaches 1, whether it diverges or ends in another cycle. Since 7 mod 8 is an odd class, that is the negation of YAH Conj. 4.13 (single class 7; the earlier round-2 referee checked the source in yah_avoid57.md). This equivalence is new relative to census/round2/upfrom1/up_ct3.md, which does not cite YAH.
- Theorem 2 re-derived. Terras with L = 3 gives 7 mod 8 <-> 111. Each class mod 2^L has at most 2 members in [1,X]. The base cases t_0..t_2 <= 2τ^L hold, and the induction is exact. The constant 4 is valid for every X >= 2.
- Independent test (my own script, using the census step `up_ct3` from census/round2/upfrom1/systems.py):
  - #(U ∩ [1,X]) <= 2 t_L <= 4 X^{log2 τ} for all X < 5000 and sampled X up to 2^18, so for non-power-of-2 X as well;
  - an exhaustive count that the classes mod 2^L avoiding 7 mod 8 in steps 0..L-3 number exactly t_L, for L = 3..14.
  
  The authors' check passes in 2.6 s.
- Caveats. The density result is an elementary counting bound, with no dependence on any open conjecture. It does not touch the open core. "≈ X^0.8792" is an upper bound, not an asymptotic.
