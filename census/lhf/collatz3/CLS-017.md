## Shared material for the 3n+d family (identical in every collatz3 note)

Notation. d is odd. F_d(n) = n/2 (n even), 3n+d (n odd). T_d is the shortcut
map n/2 or (3n+d)/2. F_d and T_d have the same cycles and the same bounded or
unbounded orbits (T_d only merges the halving forced after each odd step).
C = F_1 is the Collatz map.

### Lemma S (scaling). Proved.
If g | d (g > 0), then F_d(g m) = g F_{d/g}(m) for every integer m.
Proof: g m and m have the same parity, since g is odd. The even case is
(g m)/2 = g (m/2). The odd case is 3 g m + d = g(3m + d/g). QED

### Lemma G (gcd is invariant when gcd(d,6)=1). Proved.
If gcd(d,6) = 1, then gcd(F_d(n), d) = gcd(n, d) for every n.
Proof: gcd(n/2, d) = gcd(n, d) because d is odd. Also gcd(3n+d, d) = gcd(3n, d) = gcd(n, d)
because gcd(3,d) = 1. QED

### Lemma R (coprime part = rational 3x+1). Proved.
Let e be odd, e > 0, and n > 0 with gcd(n,e) = 1. Put y = n/e. Here y is a 2-adic integer,
called "even" when its numerator is even. Then F_e(n)/e = C(y), where C acts on
Z_(2) by y/2 or 3y+1.
Proof: n is even iff the numerator of y is even. Also (3n+e)/e = 3y+1. QED
So the F_e-orbits of positive integers coprime to e are exactly the 3x+1 orbits of positive
rationals whose reduced denominator is exactly e (when gcd(e,3)=1 the denominator stays e, by Lemma G).

### Theorem (exact reduction). Proved.
Let d > 0 with gcd(d,6) = 1. Define
  Q_e : every positive n with gcd(n,e)=1 has an eventually periodic F_e-orbit.
Then
  GLOBAL(3n+d)  <=>  AND over e | d of Q_e
                <=>  every positive rational with odd denominator dividing d has an eventually periodic 3x+1 orbit.
Here Q_1 is exactly "no divergent Collatz trajectory" (CLS-013).
Proof: write g = gcd(n,d) and n = g m, so gcd(m, d/g) = 1. By Lemma G, g is constant along the
orbit, so by Lemma S the F_d-orbit of n is g times the F_{d/g}-orbit of m, and m stays coprime to
d/g. The orbit of n is eventually periodic iff the orbit of m is. As n ranges over the positive
integers, (g, m) ranges over all pairs with g | d and gcd(m, d/g) = 1. The second form follows from Lemma R. QED
For d prime this gives GLOBAL(3n+d) <=> Q_1 AND Q_d. No implication between Q_d and
Q_1 is known in either direction, so the theorem is the precise statement of what is open.

### Corollary (cycle completeness). Proved.
For d > 0, a complete, provably finite list of cycles of 3n+d would include (Lemma S with
g = d) a complete list of Collatz cycles. That is open. So for no d in {1,3,5,7,9,13,17} is the cycle set
provably complete. For d = -1, completeness is the negative-integer 3x+1 cycle conjecture, also open.

### Lemma O (no 2-adic certificate in either direction). Proved.
Let A be a set of positive integers that is a union of residue classes mod 2^j (j >= 1),
nonempty, with T_d(A) contained in A. Then A = Z_{>0}. The same holds for F_d, because F_d-invariance implies
T_d-invariance, and for 6n+2.
Proof: take a class P_0 = {a_0 + 2^j s : s >= 0} in A. Suppose P_i = {a_i + 2^{j-i} 3^{e_i} s} with
j - i >= 1. All its members have the parity of a_i. So T_d(P_i) = {a_i/2 + 2^{j-i-1} 3^{e_i} s} or
{(3a_i+d)/2 + 2^{j-i-1} 3^{e_i+1} s}, which is again of that form. After j steps,
T_d^j(P_0) = {a_j + 3^e s : s >= 0}, and this is contained in A. Its terms a_j + 3^e s for s = 0..2^j-1 are pairwise
incongruent mod 2^j, because 3^e is odd. So A meets, and therefore contains, every class mod 2^j. QED
Consequence: route (a) cannot use a forward-closed union of 2-adic residue classes. That includes the residue-class
domain of an increasing affine return map T^K(n) = (3^k n + c)/2^K. A "yes" proof cannot use a
proper invariant 2-adic trap either. Moduli with an odd factor are not excluded, for example the invariant
sublattices dZ. In any case, route (a) is moot when GLOBAL contains Q_1.

### Theorem 1C (all cycles with one local minimum). PARTIAL.
This is conditional on a cited transcendence bound. A 1-cycle is a T_d-cycle whose parity block is
1^k 0^l: exactly one maximal run of odd steps, so exactly one local minimum x.
(i) Formula. Proved. x = d(3^k - 2^k)/(2^K - 3^k) with K = k+l. This holds because T_d^k(x) = (3/2)^k (x+d) - d
on a run of k odd steps, followed by division by 2^l. Conversely, a positive integer value of
this formula is the unique 2-adic point with periodic parity vector (1^k 0^l)^inf, so it is a 1-cycle.
For l = 0 the only primitive solution is the fixed point x = -d (k = 1), which is positive only for d < 0.
(ii) Divisibility. Proved. Put D = 2^K - 3^k, which is odd. Since d(3^k-2^k) = d 2^k (2^l - 1) - dD,
we have D | d(3^k-2^k) iff D | d(2^l - 1). Hence 0 < |D| <= |d|(2^l - 1) < |d| 2^l. Also x >= 1 forces
D > 0 and 2^K < (d+1) 3^k when d > 0, and D < 0 (2^K < 3^k) when d < 0.
(iii) Input (E), Ellison 1971 (Sem. Theorie Nombres Bordeaux, exp. 10), as quoted in the 3x+1
literature: |2^K - 3^k| > 2^K e^{-K/10} for K >= 28. I did NOT re-verify the exact statement from
the source; a web search did not confirm the constant. Under (E) with K >= 28, (ii) gives
2^k < |d| e^{K/10} with K < k log2 3 + log2(|d|+1). Hence k <= kE(d), where kE(-1) = kE(1) = 0,
kE(3) = 2, kE(5) = 3, kE(7) = kE(9) = 4, kE(13) = 5, kE(17) = 6. Then K < 6 log2 3 + log2 18 < 14 < 28,
a contradiction. So K <= 27.
Alternative input (R), Rhin 1987: |K log 2 - k log 3| >= K^{-13.3}. This gives |D| >= 2^K K^{-13.3}/3 and
k <= kR(d) <= 104 for every d here.
(iv) Finite search. Exact integers, check script. Every k <= 1000 (covers both (E) and (R)
with a wide margin, including any small-H threshold in (R)) and every admissible l is enumerated.
Each solution is verified by simulation.
Result: the complete list of 1-cycles, as (k, l, minimum):
  d=1  : (1,1,1)                       [Steiner 1977: only the trivial cycle]
  d=-1 : (1,0,1), (2,1,5)              [{1,2}, {5,14,7,20,10}]
  d=3  : (1,1,3)
  d=5  : (1,1,5), (1,2,1), (3,2,19)
  d=7  : (1,1,7), (2,2,5)
  d=9  : (1,1,9)
  d=13 : (1,1,13), (1,3,1), (5,3,211)
  d=17 : (1,1,17)                      (3n+17 has no 1-cycle coprime to 17; e.g. the 49-cycle of 27 has more minima)
Status: the algebra and the search are PROVED. Completeness for all k rests on (E) or (R), which are
published effective Baker/Pade-type bounds cited here, not reproved. ellison_sanity() is a numerical sanity check of
(E) for K <= 1000, nothing more.

### Collapse of the list (proved equivalences)
  P1  := no divergent Collatz trajectory.
  P-1 := no divergent 3x+1 trajectory on negative integers.
  CLS-031 <=> CLS-013 <=> CLS-014 <=> CLS-017 <=> P1
  CLS-018 <=> P-1
  CLS-015 <=> P1 AND Q5;  CLS-016 <=> P1 AND Q7;  CLS-011 <=> P1 AND Q13;  CLS-012 <=> P1 AND Q17
  (Q_p = no divergent 3x+1 orbit among positive rationals with denominator exactly p.)
So the nine items reduce to six statements, P1, P-1, Q5, Q7, Q13 and Q17, and each of
CLS-015/016/011/012 implies CLS-013. These are KNOWN-HARD, at least as hard as Collatz divergence. I give no
resolution.


## Referee (adversarial check)
Verdict: CONFIRMED (restatement).

Corrected claim: GLOBAL(3n+9) <=> P1 is correct and is already in the notes (orbits enter 9Z, and F_9(9y) = 9C(y)). The only 1-cycle is 9*{1,2}, conditional on Ellison/Rhin, or directly by Steiner.

Checks run by the referee: check_CLS-017.py exits 0 (under 1 s). The referee's own test, referee_check.py, also exits 0 (about 3 s). It is written against census/systems.py and does not use _common.py. It re-verifies the scaling and sublattice orbit identities, gcd invariance, entry into 3Z/9Z, and the 6n+2 orbit embedding. It enumerates 1-cycles independently for k <= 400 and cross-checks them against a brute-force list of all T_d-cycles with minimum < 20000, including the number of odd runs in each. It also re-derives the Ellison step k <= kE(d), then K < 28, in rational arithmetic.

What the referee re-derived by hand:
- Lemma S, Lemma G, Lemma R and the reduction theorem are correct.
- Lemma O is correct, including for 6n+2: a G-invariant set A is T_1-invariant because T_1(n) lies on the G-orbit of n.
- In Theorem 1C, the identity d(3^k-2^k) = d 2^k(2^l-1) - dD holds, so D | d(2^l-1) and 0 < |D| <= |d|(2^l-1) when l >= 1. With Ellison's inequality this gives k(ln2 - log2(3)/10) < ln|d| + log2(|d|+1)/10, the stated kE values, and then K < 14. A positive integer value of the formula is a genuine cycle, because it is the 2-adic point with the given periodic parity vector. Local minima of a T_d-cycle correspond one-to-one with its maximal odd runs.

Caveats:
- (E) is quoted, not checked against Ellison's paper. Its usual quoted form, |2^x-3^y| > 2^x e^(-x/10) for x >= 28, matches what the note uses.
- The quoted (R) exponent may be inexact. Simons and de Weger quote Rhin in the form exp(-13.3(0.46057 + log max)), which is weaker by a constant factor. That changes kR by about 10, so the exact search to k = 1000 still covers it.
- The 1-cycle classification is therefore a theorem only modulo a published effective bound. It is not self-contained.
- For d = 1 it is Steiner's 1977 theorem. 1-cycles of 3x+d may already be classified in the literature (Belaga and Mignotte 1998). The referee did not check this.
