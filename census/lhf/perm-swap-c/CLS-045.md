# CLS-045 [perm_c_s8] GLOBAL — lhf/perm-swap-c

**Map.** C: 2q -> 3q, 4q+1 -> 3q+2, 4q+3 -> 3q+1. This is C = S^{-1}, the inverse of perm_swap (CLS-047).
**Question.** GLOBAL: is every orbit a finite cycle?

**Status: PARTIAL (proved obstructions). GLOBAL(C) is literally the same question as GLOBAL(S) = CLS-047, and it remains OPEN.**

* **Equivalence.** C and S have the same orbits, because C = S^{-1}, which is verified by hand and on 1..1e5. So CLS-045 and CLS-047 are one problem. The census already noted this, and it is restated here so the list can merge the two items.
* **No periodic separator.** By CLS-047.md Theorem A ("Inverses" paragraph), a periodic set is C-closed iff its complement is S-closed. So the C-closed periodic sets are exactly ∅, Z_{>0}, 5Z_{>0} and Z_{>0}\5Z_{>0}. C preserves 5-divisibility: if 5 | n then C(n) = 5·T^{-1}(n/5), and the non-multiples of 5 map among themselves (complement argument). So no congruence certificate proves any C-orbit infinite, at any modulus and any seed.
* **No invariant affine progression.** The slopes of C^k are 3^k/2^h with h >= k >= 1, which are never integers. By CLS-047.md Theorem B, no arithmetic progression is invariant under an affine C^k, so there is no increasing affine subsequence certificate.
* A backward-orbit route gives nothing new: a backward orbit of C is a forward orbit of S, which is covered by the same theorems.
