# CLS-047 [perm_swap_s8] GLOBAL — lhf/perm-swap-c

**Map.** S: 3q -> 2q, 3q+1 -> 4q+3, 3q+2 -> 4q+1 (a bijection of Z_{>0}; S(n) = 5 T(n/5) with T the 1932 map).
**Question.** GLOBAL: is every orbit a finite cycle? (Expected: no.)

**Status: PARTIAL (proved obstructions); GLOBAL itself still OPEN.**

No infinite orbit was found or proved. What is proved here:

* **Theorem A (no periodic separator, for any modulus or seed).** For every M >= 1, the only unions of residue classes mod M that S maps into themselves are: the empty set, all of Z_{>0}, 5Z_{>0}, and Z_{>0} \ 5Z_{>0} (the last two occur only when 5 | M). n and S(n) are always both multiples of 5 or both not. So no periodic forward-closed set contains S(n) but not n. The congruence-separator route (a) therefore cannot prove any S-orbit infinite. The same holds for C = S^{-1} (CLS-045), T (CLS-038) and T^{-1}, where T and T^{-1} have only the two trivial closed sets.
* **Theorem B (no invariant affine progression).** For every k >= 1 there is no infinite arithmetic progression P = {r + m t : t >= 0} such that S^k is affine on P and S^k(P) ⊂ P. The same holds for T, T^{-1} and C. This rules out the "strictly increasing affine subsequence on an invariant class" certificate.
* Theorem A also gives the written-out proof that the census reference `certificate_search_proofs.txt` §5 sketches for T, which had not been reviewed.

What does *not* carry over from T: S on 5Z is exactly T (S(5y) = 5T(y)), but S on the non-multiples of 5 is T acting on rationals with denominator 5. No equivalence between GLOBAL(S) and GLOBAL(T) was found in either direction beyond the known one (GLOBAL(S) = yes implies GLOBAL(T) = yes). GLOBAL(S) = no is *not* implied by GLOBAL(T) = no.

## Setting

For a bijection F of Z_{>0} and M >= 1, let G_M(F) be the directed graph on Z/M with an edge r -> F(n) mod M for every n > 0, n ≡ r (mod M). A *periodic set* is U_R = {n > 0 : n mod M ∈ R}. U_R is F-closed iff R is closed under successors in G_M(F), because every residue class mod M contains positive integers of every residue mod (branch modulus)·M. A *separator at x* is an F-closed U with F(x) ∈ U and x ∉ U. It would certify that x is not periodic, since if x were periodic then x = F^{L-1}(F(x)) ∈ U. A closed set is a union of strongly connected components (SCCs) that contains all its successors. So a separator exists at some x iff some edge of G_M(F) goes between different SCCs.

Branch data. T: (a_i, b_i) = (2,0), (4,1), (4,3) for n = 3q+i -> a_i q + b_i. S: (2,0), (4,3), (4,1). As rational affine maps of n:
T: A_0 = 2n/3, A_1 = (4n-1)/3, A_2 = (4n+1)/3. S: A_0 = 2n/3, A_1 = (4n+5)/3, A_2 = (4n-5)/3.

## Proof of Theorem A

**Step 0 (5-divisibility).** S(3q) = 2q, and 5 | 3q iff 5 | q iff 5 | 2q. For 3q+1, 5 | 3q+1 iff q ≡ 3 (mod 5) iff 5 | 4q+3. For 3q+2, 5 | 3q+2 iff q ≡ 1 (mod 5) iff 5 | 4q+1. So S maps 5Z_{>0} into itself and maps the non-multiples of 5 into themselves. Hence, when 5 | M, no edge of G_M(S) joins {r : 5|r} and {r : 5∤r}.

**Step 1 (lifting full ternary fibres).** Write M = 3^j m with 3 ∤ m, and let π : Z/M -> Z/m be reduction. Let F be T or S. Because 3 is invertible mod m, the maps A_i are affine maps of Z/m, and F(n) ≡ A_{n mod 3}(n) (mod m). Let H_m be the graph on Z/m with edges c -> A_i(c) for i = 0, 1, 2.

(a) Fix n > 0 and t >= 0, and put n' = n + 3^j m t. Inductively, after s <= j steps F^s(n') - F^s(n) = (prod of the s slopes a) · 3^{j-s} m t, so the first j branch choices of n and n' agree. Hence F^j(n') = F^j(n) + 2^h m t for some h. As t runs over 0..3^j-1, the values 2^h m t mod 3^j m are m·(all of Z/3^j). So {F^j(n') mod M} is the full fibre π^{-1}(F^j(n) mod m).

(b) Fix c ∈ Z/m and i. The integers n = 3q+i > 0 with n ≡ c (mod m) have q in one fixed class mod m and q free mod 3^j (by CRT). Then F(n) = a_i q + b_i is ≡ A_i(c) (mod m), and since a_i ∈ {2, 4} is a unit mod 3, it takes every value mod 3^j. So F maps the full fibre over c onto the full fibre over A_i(c).

By (a) and (b), from any r ∈ Z/M the graph G_M(F) reaches the full fibre over c_0 = π(F^j(r̃)), where r̃ is a positive representative of r. From there it reaches the full fibre over every vertex that H_m reaches from c_0.

**Step 2 (H_m, 3 ∤ m).** Write m = 2^b w with w odd. By CRT, the A_i act on Z/2^b × Z/w coordinatewise.

*On Z/w* every A_i is a bijection, since 2/3 and 4/3 are units. In a finite permutation group every inverse is a positive word, so A_1 ∘ A_2^{-1} is a word. As rational maps it is the translation y -> y - 2/3 for T and y -> y + 10/3 for S (checked in check_CLS-047.py).
- T: translation by the unit -2/3 is transitive on Z/w.
- S with 5 ∤ w: 10/3 is a unit, so the translation is transitive.
- S with 5 | w: the translations generate +5Z/w, whose orbits are the classes mod 5. Also A_1(c) ≡ 4c·3^{-1} ≡ 3c (mod 5), and 3 generates (Z/5)^*. So the group is transitive on {c : 5∤c}, and it maps 5Z/w to itself.

*Adding the 2-part.* Take a target s ∈ Z/m and a positive integer s̃ ≡ s (mod m). Let u = F^{-b}(s̃) (F is a bijection), and let W be the length-b branch word taking u to s̃. As a rational affine map W(x) = (2^h/3^b)x + β with h >= b, so for every x we get W(x) ≡ β ≡ W(u) = s̃ (mod 2^b). On Z/w, W is a bijection with W(u) ≡ s. Choose a word V whose action on Z/w sends c to u mod w. For S this is possible whenever c and s have the same 5-divisibility (5 | w when 5 | m), because u has the same 5-divisibility as s̃ by Step 0. Every word is a path in H_m, because all three branches are available from every vertex. Then W(V(c)) ≡ s mod 2^b and mod w, so c reaches s in H_m.

**Step 3 (assembly).** Take r, s ∈ Z/M; for S with 5 | M, also assume they have the same 5-divisibility. π(F^j(r̃)) then has the 5-divisibility of r by Step 0. By Steps 1 and 2, r reaches the full fibre over π(s), and that fibre contains s. So G_M(T) is strongly connected. G_M(S) is strongly connected if 5 ∤ M. If 5 | M, its SCCs are exactly {5|r} and {5∤r}, and no edge joins them (Step 0). Every edge stays inside an SCC, so no separator exists.

**Inverses.** If U is F-closed then Z_{>0} \ U is F^{-1}-closed: if n ∉ U and F^{-1}(n) ∈ U, then n = F(F^{-1}(n)) ∈ U, a contradiction. The same argument run with F^{-1} gives the converse. So the periodic F^{-1}-closed sets are the complements of the F-closed ones, which is the same list. For C = S^{-1}, n and C(n) also have the same 5-divisibility, so C has no separator either. ∎

## Proof of Theorem B

Suppose S^k(r + m t) = a(r + m t) + b for all t >= 0 and the image lies in P. Subtracting the cases t = 1 and t = 0 gives a·m ∈ mZ, so a ∈ Z. Split P into the sub-progressions modulo 3^k m that fix the branch word. Each is infinite, and on each S^k equals that word's affine map. That map agrees with the given affine map at infinitely many points, so the two are equal, and a = 2^h/3^k ∉ Z for k >= 1. This is a contradiction. For T the argument is identical. For T^{-1} and C the slopes are 3^k/2^h with h >= k >= 1, which are also never integers. ∎

## Remaining routes

The orbit-infinitude certificates that are still possible need non-periodic state: automata in base 2 or 3, or nonlinear invariants. A congruence or affine-progression certificate cannot exist for these four maps. S on 5Z is T itself, so a proof for S at a seed in 5Z is exactly a proof for T. Seeds not divisible by 5 are T-orbits of rationals with denominator 5, which is no easier by any measure found here.
