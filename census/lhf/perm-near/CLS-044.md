# CLS-044 — perm_b_s7, GLOBAL

**Map.** B: 3q -> 4q; 3q+1 -> 4q+2; 3q+2 -> 2q+1 (on Z>0).
**Question.** GLOBAL: is every positive B-orbit eventually periodic?

**Result.** EQUIVALENT (exactly) to GLOBAL for the 1932 permutation T (CLS-040), by the conjugacy B(n) = T(n+1) - 1. Status: **PROVED equivalence**; the problem stays OPEN (KNOWN-HARD).

## Proof

T is the 1932 permutation 3q -> 2q, 3q+1 -> 4q+1, 3q+2 -> 4q+3; it is a bijection of Z>0 (see CLS-041).

1. *Identity.* n = 3q: T(3q+1) - 1 = 4q. n = 3q+1: T(3q+2) - 1 = 4q+2. n = 3q+2: T(3q+3) - 1 = 2(q+1) - 1 = 2q+1. So B(n) = T(n+1) - 1 for all n >= 1.
2. *Invariant domain.* T(1) = 1 and T is a bijection, so T maps Z>=2 bijectively onto Z>=2.
3. *Conjugacy.* With tau(n) = n+1, a bijection Z>0 -> Z>=2, B = tau^{-1} ∘ T ∘ tau on Z>0. So B^k(7) = T^k(8) - 1 for all k >= 0.
4. *Same answer.* For a bijection "eventually periodic" means "periodic" (an injective orbit cannot enter a cycle avoiding its seed). n is B-periodic iff n+1 is T-periodic. So every B-orbit is periodic iff every m >= 2 is T-periodic iff (as T(1) = 1) every T-orbit is periodic.
