# CLS-043 — perm_b_s7, FATE of 7

**Map.** B: 3q -> 4q; 3q+1 -> 4q+2; 3q+2 -> 2q+1 (on Z>0).
**Question.** FATE: does the B-orbit of 7 return to 7, enter another cycle, or grow forever?

**Result.** EQUIVALENT (exactly) to Collatz's 1932 orbit-of-8 problem (CLS-039), by the conjugacy B(n) = T(n+1) - 1. Status: **PROVED equivalence**; the problem stays OPEN (KNOWN-HARD).

## Proof

T is the 1932 permutation 3q -> 2q, 3q+1 -> 4q+1, 3q+2 -> 4q+3; it is a bijection of Z>0 (see CLS-041).

1. *Identity.* n = 3q: T(3q+1) - 1 = 4q. n = 3q+1: T(3q+2) - 1 = 4q+2. n = 3q+2: T(3q+3) - 1 = 2(q+1) - 1 = 2q+1. So B(n) = T(n+1) - 1 for all n >= 1.
2. *Invariant domain.* T(1) = 1 and T is a bijection, so T maps Z>=2 bijectively onto Z>=2.
3. *Conjugacy.* With tau(n) = n+1, a bijection Z>0 -> Z>=2, B = tau^{-1} ∘ T ∘ tau on Z>0. So B^k(7) = T^k(8) - 1 for all k >= 0.
4. *Same fate.* B^p(7) = 7 iff T^p(8) = 8. Both maps are injective, so neither orbit can enter a cycle not containing its seed; the two FATE questions have the same answer.
