# CLS-054 — flipT_s8, FATE of 8

**Map.** P(n) = T(n)+1 if T(n) odd, T(n)-1 if T(n) even; branch by branch 3q -> 2q-1, 3q+1 -> 4q+2, 3q+2 -> 4q+4.
**Question.** FATE of the seed 8.

**Result.** EQUIVALENT (exactly) to Collatz's 1932 orbit-of-8 problem (CLS-039), by P(n) = T(n+3) - 3. Status: **PROVED equivalence** (the round-2 reduction is confirmed); the problem stays OPEN (KNOWN-HARD).

## Proof

1. *Branch form.* T(3q) = 2q is even, so P(3q) = 2q-1; T(3q+1) = 4q+1 is odd, so P = 4q+2; T(3q+2) = 4q+3 is odd, so P = 4q+4.
2. *Identity.* T(3q+3) - 3 = 2(q+1) - 3 = 2q-1; T(3q+4) - 3 = 4(q+1)+1-3 = 4q+2; T(3q+5) - 3 = 4(q+1)+3-3 = 4q+4. So P(n) = T(n+3) - 3 for all n >= 1.
3. *Invariant domain.* T(1) = 1, T(2) = 3, T(3) = 2, so T permutes {1,2,3}; T being a bijection of Z>0, it maps Z>=4 bijectively onto Z>=4.
4. *Conjugacy.* With tau(n) = n+3 (a bijection Z>0 -> Z>=4), P = tau^{-1} ∘ T ∘ tau on Z>0. Hence P^k(8) = T^k(11) - 3.
5. *Same fate.* T(8) = 11 and T is a bijection, so 11 is T-periodic iff 8 is. Thus P^p(8) = 8 for some p iff T^p(11) = 11 for some p iff 8 is T-periodic. Both maps are injective, so "other cycle" is impossible for both, and the FATE questions coincide.
