# CLS-055 — swT9_s8, FATE of 8

**Map.** Q(n) = sigma(T(n)), where T is the 1932 permutation (3q -> 2q, 3q+1 -> 4q+1, 3q+2 -> 4q+3) and sigma swaps 9 <-> 10 (mod 18). Q is a permutation of Z>0, affine on each class mod 27, with slopes 2/3 and 4/3.
**Question.** FATE of the seed 8 (return, or infinite; "other cycle" is impossible because Q is injective).

**Result.** Status: **PARTIAL**. The FATE question remains open. What is new and proved here is an obstruction: congruence traps cannot settle it, and they cannot show that any Q-orbit at all is infinite, for these moduli:
- every modulus K with 3 ∤ K (general proof below);
- every K <= 1200, and every K = 2^a 3^b <= 300000 (exact finite computation).

Earlier work only excluded separators for the seed 8, for K <= 150 and a few more values (see `round2/downfrom5/swT9_s8.md`). The DFA exclusion is also extended, to <= 6 states in base 2, <= 4 in base 3, and <= 3 in base 6, reading both MSD-first and LSD-first.

One heuristic correction to the notes: the expected drift of Q is **not** T's. See the last section.

## Definitions

G_K is the residue graph mod K. It has an edge x -> y iff some n >= 1 with n ≡ x (mod K) has Q(n) ≡ y (mod K). A *congruence trap* mod K is a nonempty set D of residues mod K, D not equal to all of Z/K, whose union of classes satisfies Q(D) ⊆ D.

**Lemma 0.** If G_K is strongly connected, there is no congruence trap mod K. Hence no union of classes mod K contains Q(8) and avoids 8, and no union of classes mod K is Q^{-1}-forward-closed either (its complement would be a Q-trap).
*Proof.* Every edge of G_K is realised by an actual n. So a Q-closed union D is closed under the edges of G_K. From any x in D every residue is reachable, so D is everything.

This matters because a trap is the standard route-(a) certificate. If D is a Q-closed union of classes with Q(D) ⊊ D, then every x in D \ Q(D) has an infinite orbit. If 8 is not in D but Q(8) is, then 8 never returns. Lemma 0 removes both at these moduli.

## Theorem (all K with 3 ∤ K)

For every K with 3 ∤ K, the graph G_K is strongly connected.

*Step 1 (Q contains T's pieces).* On the classes n ≡ 0, 1, 2 (mod 27), Q = T. Indeed T(27t) = 18t ≡ 0, T(27t+1) = 36t+1 ≡ 1 and T(27t+2) = 36t+3 ≡ 3 (mod 18), and none of these is 9 or 10. Since gcd(K, 27) = 1, CRT gives, for every x mod K and each r in {0, 1, 2}, some n >= 1 with n ≡ x (mod K) and n ≡ r (mod 27). For that n, 3Q(n) = 2n, 4n-1 or 4n+1. Since 3 is invertible mod K, G_K contains the edges x -> g0(x), g1(x), g2(x), where
g0(x) = 2x/3, g_-(x) = (4x-1)/3, g_+(x) = (4x+1)/3 (computed in Z/K).
It therefore suffices to show that the graph generated by g0, g_-, g_+ on Z/K is strongly connected. Write K = 2^a m with gcd(m, 6) = 1. For a word w, g_w is the composition, and e(w) is the 2-adic valuation of its slope: +1 for each g0 and +2 for each g_±.

*Step 2 (2-adic steering).* Claim C(a): for every y mod 2^a there is a word w with e(w) >= a and g_w(z) ≡ y (mod 2^a) for **every** z. The g's commute with reduction mod 2^a, because 3 is a 2-adic unit. The proof is by induction on a, and C(0) holds with the empty word.
- If y is even, put y' = 3y/2 mod 2^{a-1} and take w' from C(a-1). Then g0 ∘ g_{w'}(z) = (2/3)(y' + 2^{a-1}s) = y + 2^a(s/3) ≡ y (mod 2^a), and e = e(w') + 1 >= a.
- If y is odd, choose ε in {±1} with 3y ≡ ε (mod 4). Put y' = (3y - ε)/4 mod 2^{max(a-2,0)} and take w' from C(max(a-2,0)). Then g_ε ∘ g_{w'}(z) = (4(y' + 2^{a-2}s) + ε)/3 = y + 2^a(s/3) ≡ y. For a = 1 the inner requirement is vacuous, and (4z+ε)/3 is odd. Also e = e(w') + 2 >= a.

*Step 3 (mod m).* The maps g0, g_± are permutations of Z/m, because 2/3 and 4/3 are units there. Their group contains g_+ ∘ g_-^{-1}: y -> y + 2/3. This holds because g_-^{-1}(y) = (3y+1)/4, and applying g_+ gives (3y+2)/3. Since 2/3 is a unit mod m, the group is transitive on Z/m. Every group element is a positive word, since g^{-1} = g^{ord(g)-1}.

*Step 4 (combine).* Take x, y in Z/K and write y = (y_2, y_m) by CRT. Take v from C(a) for y_2. Since g_v is a permutation of Z/m, take a positive word u with g_u(x) ≡ g_v^{-1}(y_m) (mod m), using Step 3. Then g_v(g_u(x)) ≡ y_2 (mod 2^a), because Step 2 holds for every input, and it is ≡ y_m (mod m). So y is reachable from x. ∎

So any congruence trap for Q, and any congruence separator for the seed 8, needs a modulus divisible by 3. A trap mod K is also a trap mod every multiple of K, so this says only that the *minimal* modulus of a trap would have to be a multiple of 3.

## Exact computation (other moduli)

`check_CLS-055.py` builds G_K exactly. Q is affine mod 27. For each lift class of x, the residues Q(n) mod K hit are exactly base + gcd(K, step)·Z, all realised by positive n. The script verifies that G_K is strongly connected for every K <= 1200 and for all 78 values K = 2^a 3^b in (1200, 300000]. For each such K, this proves by Lemma 0 that no congruence trap exists. (The task asked for 2^a 3^b <= 10^4; the check covers that range and more.)

I did not find a proof for general K divisible by 6. The analogous backward argument works for T^{-1} modulo 3^b, but for Q^{-1} with 9 | K the sigma-altered pieces fall on whole classes (x ≡ 0, 1 mod 9), so Step 1 does not carry over.

## Automata (DFA certificates)

A certificate is a DFA reading canonical base-b digits, MSD- or LSD-first. It must reject 8, accept Q(8), ..., Q^26(8), and satisfy (n accepted ⇒ Q(n) accepted) for 1 <= n <= 3000. These are necessary conditions for a true certificate. Search is exhaustive backtracking: transitions are assigned lazily, states are relabelled in order of first use, and all accepting sets are enumerated. Results:
- base 2, <= 6 states: none (MSD and LSD);
- base 3, <= 4 states: none (MSD and LSD);
- base 6, <= 3 states: none (MSD and LSD).
"None" is a proof that no certificate of that size exists. As a positive control, the same routine finds certificates for n -> 3n (base 3, 2 states) and n -> 2n (base 2, 6 states).

## Heuristic correction (not a proof)

The round-2 note says that Q's drift equals T's, (1/3)log(2/3) + (2/3)log(4/3), about 0.082 bits per step. That is not right for Q. In the Markov chain on G_K with Haar weights, the stationary mass on n mod 3 is about (0.2381, 0.4286, 0.3333), which looks like (5/21, 9/21, 7/21) at every K in {27, 54, ..., 1458}. This gives a drift of about 0.177 bits per step. The orbit of 8 matches: after 1e5 steps it has 17478 bits, and the residues mod 3 occur at frequencies (0.240, 0.430, 0.330). For T the figure is 8066 bits. So 8 is expected to escape even faster than under T. This is evidence only.

## Check

`check_CLS-055.py` checks Q against the catalog on 1..2e5, affinity mod 27, the pieces 0, 1, 2 mod 27 equal to T, strong connectivity for the moduli above, the DFA non-existence with positive controls, and no return within 1e5 steps. It exits 0 and takes about 31 s.

## Referee

**Verdict: CONFIRMED as PARTIAL (obstruction only; FATE stays open).**
- Theorem (3 ∤ K): I checked every step. Step 1: T(27t)=18t, T(27t+1)=36t+1 and T(27t+2)=36t+3 avoid 9 and 10 mod 18, so Q = T there, and CRT gives the edges g0, g_± in G_K. Step 2: y' = (3y-ε)/4 mod 2^{a-2} gives 4y'+ε ≡ 3y (mod 2^a), and the induction holds uniformly in the input. Step 3: g_+∘g_-^{-1} = translation by 2/3, which is transitive mod m coprime to 6, and inverses are positive words in a finite group. Step 4: the order of composition is right. Lemma 0 is right, and the complement argument for Q^{-1} uses bijectivity, which holds. The theorem is correct. As the author notes, it only forces the minimal trap modulus to be divisible by 3. It does not exclude traps at all K.
- Finite moduli: independently, I built G_K from actual integers n <= 3·lcm(K,27). That gives a subgraph of the true graph, so strong connectivity of the subgraph is a valid proof. All K <= 300 and K in {324,432,486,576,648,729,864,972,1152,1296,1458,2187,2592} came out strongly connected. I did not re-run the remaining K up to 1200 or 3e5 independently. check_CLS-055.py passes (exit 0, ~31 s), and its exact affine residue-graph construction is sound because Q is affine on classes mod 27.
- DFA: an independent brute force over all DFAs found no certificate for base 2 with <= 4 states (with closure tested only to n <= 400, which is weaker and therefore stronger evidence), base 3 with <= 2 states, MSD and LSD. The positive control (3n) is found. The larger sizes (base 2 with 5 and 6 states, base 3 with 3 and 4, base 6 with 3) rest on the author's backtracking, which I have not re-implemented. The conditions used are necessary ones, so 'none' is a valid exclusion if the search is truly exhaustive.
- Drift: this is a heuristic, correctly labelled as one. The orbit of 8 (17478 bits after 1e5 steps) supports it. It is not a proof of anything.
Corrected claim: proved that G_K is strongly connected (no congruence trap or separator) for all K with 3 ∤ K. Computed the same for K <= 1200 and K = 2^a 3^b <= 3e5 (independently spot-checked for K <= 300 and selected 2^a 3^b <= 2592). DFA exclusions hold to the stated sizes (independently re-verified only for the small sizes). FATE of 8 is open.
