# CLS-042 — perm_1932inv_s8, GLOBAL

**Map.** U: 2q -> 3q; 4q+1 -> 3q+1; 4q+3 -> 3q+2 (on Z>0).
**Question.** GLOBAL: is every positive U-orbit eventually periodic?

**Result.** EQUIVALENT (exactly) to GLOBAL for the 1932 permutation T (CLS-040, also CLS-038). Status: **PROVED equivalence**; the problem itself stays OPEN (KNOWN-HARD).

## Proof

1. *U is T^{-1}.* Branch by branch: T(3q) = 2q and U(2q) = 3q; T(3q+1) = 4q+1 and U(4q+1) = 3q+1; T(3q+2) = 4q+3 and U(4q+3) = 3q+2. So U∘T = id on Z>0. Conversely U(2q) = 3q, T(3q) = 2q; U(4q+1) = 3q+1, T(3q+1) = 4q+1; U(4q+3) = 3q+2, T(3q+2) = 4q+3, so T∘U = id on Z>0 (every positive integer is 2q with q>=1, or 4q+1, 4q+3 with q>=0). Hence T is a bijection of Z>0 and U = T^{-1}.
2. *Fate (b) is impossible for both maps.* For an injective F, if the orbit of x first meets a cycle C at y = F^k(x), k>=1, with x not in C, then y has two preimages (F^{k-1}(x) and its predecessor in C). So each orbit either returns or is infinite.
3. *Same answer.* By 2, "every orbit eventually periodic" means "every x is periodic" for both maps. If T^p(x) = x then U^p(x) = x, and conversely. So every U-orbit is periodic iff every T-orbit is periodic: the GLOBAL questions coincide (the cycles of U are the cycles of T traversed backwards).

## Check

`check_CLS-042.py` (runs `_equiv.py inv`, exit 0): against the catalog step functions, U = T^{-1} and T = catalog T on 1..2e5. Both T∘U and U∘T are affine in q on each class, so agreement at q = 0, 1 per class (checked, with q < 2000 as a cross-check) is itself a proof of the identities. 

## Referee

**Verdict: CONFIRMED (already known in substance).** Since U = T^{-1} is a bijection of Z>0, eventually periodic means periodic, and the U-periodic points are exactly the T-periodic points. So GLOBAL(U) is exactly GLOBAL(T) = CLS-040 (= CLS-038). This refines the list's wording 'equivalent to 1932 orbit of 8': GLOBAL is the stronger, all-orbits question, and it contains the orbit-of-8 problem.
