# CLS-037 — 9n+1, GLOBAL

Map: even n -> n/2; odd n -> 9n+1. Question: is every positive orbit eventually periodic?

**Status: PARTIAL (GLOBAL remains OPEN).**

1. **Theorem C (q = 9): 9n+1 has no cycle with at most 1000 odd terms.** The proof is the exact enumeration
   argument of CLS-032.md. Any cycle with k odd terms has least odd term n with
   (9n+1)^k ≥ 2^{K_0} n^k, where K_0 is the least integer with 2^{K_0} > 9^k. All such n were tested
   exactly. An extra run with L = 3000 (all n ≤ 464416) also found no cycle.
   Since every cycle has an odd term, **every eventually periodic 9n+1 orbit ends in a cycle with more
   than 1000 (indeed more than 3000) odd terms, hence of length more than 2000 (6000).**
   Remark (an exact reformulation, not a resolution): GLOBAL = "no" follows at once if 9n+1 has no
   cycle at all. A non-eventually-periodic orbit takes infinitely many distinct values, so it is unbounded.
   Conversely, "no cycles" is the strongest form of "no". Proving that no cycle exists for every k is a
   Steiner / Simons–de Weger type Diophantine problem (n(2^K − 9^k) = Σ 9^{k−1−i} 2^{A_i}) and was not achieved.
2. **Theorem A (q = 9, CLS-032.md):** every nonempty forward-closed union of residue classes, at any modulus,
   contains 1. Hence (route (a)) no congruence trap certifies a divergent orbit. Note that 1 itself is not
   known to be periodic, so for 9n+1 this does not even say the trap contains a cycle. It says the trap
   contains the orbit of 1, whose fate is CLS-036.

Check: `check_CLS-037.py` (exit 0).

## Referee (adversarial check)

**Verdict: CONFIRMED with correction.** Theorem C for q=9 holds: no cycle has at most 1000 odd terms (independent re-run). The L=3000 claim was not independently confirmed in the referee's time budget; only L=1000 is verified. Theorem A for q=9 is correct as stated: every trap contains 1. But the sentence 'Hence (route (a)) no congruence trap certifies a divergent orbit' is NOT justified, and the caveat right after it contradicts it. Since 1 is not known to be periodic, Theorem A does not exclude a trap free of periodic points; if 9n+1 has no cycles, Z_{>0} is one. Corrected: every congruence trap contains the orbit of 1, so a route-(a) certificate would have to prove the orbit of 1 (CLS-036) unbounded. 'No cycles at all implies GLOBAL = no' is a correct but trivial reformulation. GLOBAL stays OPEN.

Independent test: `referee_check.py` (exit 0, about 55 s; written without sevnine_lib, uses the census/systems.py steps). It checks Theorem A at **every** modulus M <= 240 (odd moduli included, with the residue graph built from actual images of r+Mt), the Step-3 lemma directly on Z/m for all admissible m < 1500, and Theorem C with an independent implementation (B_k by binary search; the full, unaccelerated map). The author's check scripts also pass (exit 0, 3-9 s each).

Proof re-derivation, checked line by line and correct:
- Step 1, the 2-adic (or 3-adic) loss: q is invertible mod 2^{a-b}.
- Step 2: R_m is closed under h and h∘g, and hence under g, since h has finite order.
- Step 3: on Z/m', D^{-1} g D g^{-1} is x -> x - 1/2 (for m3_e, g_1 g_2^{-1} is x -> x + 1). On Z/p^e, g^j is constant for j >= e, and that constant is a unit in <2> (in <3> for m3_e), by LTE or primitivity.

Theorem C: the product identity prod(q + r_i/n_i) = base^K and the monotone bound that gives B_k are correct, and the enumeration is exhaustive for k <= L.

Strengthening noted by the referee (not needed for the verdict): Theorem A also covers truncated traps F = {n >= N : n mod M in R}. Steps 1-3 go through for elements >= N, so F contains every large n = 1 mod m. It therefore contains some 2^j (3^j for m3_e), whose forward orbit reaches 1. Hence 1 is in F.
