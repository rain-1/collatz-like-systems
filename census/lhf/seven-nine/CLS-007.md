# CLS-007 — m3_e, GLOBAL

Map T: 3|n -> n/3; n ≡ 1 (mod 3) -> 7n+2; n ≡ 2 (mod 3) -> 7n+1. Question: is every positive orbit
eventually periodic?

**Status: PARTIAL (GLOBAL remains OPEN).** A compact form: for 3 ∤ n, T(T(n)) = ⌈7n/3⌉ (3k+1 -> 7k+3, 3k+2 -> 7k+5). This is a
reformulation only; no conjugacy to a solved map was found.

## Theorem A (m3_e): obstruction to congruence traps, every modulus

If F ⊆ Z_{>0} is nonempty, a union of residue classes mod some M, and T(F) ⊆ F, then 1 ∈ F (and so the
cycle {1,9,3} ⊆ F). This sharpens the census note "every class mod 3^j contains numbers that descend"
to all moduli. No forward-closed set of residue classes consists of divergent orbits, so route (a)
is impossible. For every seed and every M, the residue-graph closure contains the class of 1.

**Proof.** Refine so that M = 3^a m with a ≥ 1 and 3 ∤ m. Let P(c,b) = {n > 0 : n ≡ c (mod 3^b m)}, 0 ≤ b ≤ a.

*Step 1.* Let P(c,b) ⊆ F with b ≥ 1. If 3 | c, then P(c/3, b−1) ⊆ F (n' in it gives 3n' ∈ P(c,b), T(3n') = n').
If 3 ∤ c, then T(c + 3^b m t) = (7c + r_c) + 7·3^b m t, with r_c = 2 or 1. Since 7 is invertible mod 3^{a−b},
the images meet every M-class in P(7c+r_c, b), so P(7c+r_c, b) ⊆ F. Here 3 | 7c + r_c. So b drops at least
every second step, and F contains a full class P(s,0) = {n ≡ s mod m}.

*Step 2.* If P(s,0) ⊆ F, split it by n mod 3 into the three classes P(·,1) and apply Step 1. This gives
P(s/3, 0), P((7s+2)/3, 0), P((7s+1)/3, 0) ⊆ F, with arithmetic in Z/m (3 is a unit). So
R_m = {s : P(s,0) ⊆ F} is closed under h(x) = x/3, h∘g_1, h∘g_2, where g_1(x) = 7x+2 and g_2(x) = 7x+1.
h is a permutation of Z/m, so R_m is closed under g_1, g_2, h and all words in them.

*Step 3 (Lemma): for every m with 3 ∤ m, every s ∈ Z/m is sent to 1 by some word.* Write m = 7^e m' with
7 ∤ m' (m' may be even). On Z/m', g_1, g_2 and h are permutations, and g_1∘g_2^{−1}(x) = 7·(x−1)/7 + 2 = x+1
is a translation. On Z/7^e, g_2^j(x) = 7^j x + (1 + 7 + ... + 7^{j−1}) is constant for j ≥ e, with value c ≡ 1
(mod 7). This c is a unit, and 3 is a primitive root mod 7^e (order 6 mod 7, and 3^6 = 729 ≢ 1 mod 49), so
c = 3^β for some β, and h^β(c) = 1. Take N_0 ≥ e+1, a common multiple of the orders of g_2 and h on Z/m'.
Then τ = g_1 ∘ g_2^{N_0−1} acts as x -> x+1 on Z/m' and as a constant on Z/7^e. Let ω = h^β ∘ g_2^e
(a permutation π of Z/m', and it sends that constant to 1 mod 7^e). Choose j ≥ 1 with s' + j ≡ π^{−1}(1)
(mod m'). Then ω τ^j(s) ≡ 1 (mod m). ∎ So 1 mod m ∈ R_m and 1 ∈ P(1,0) ⊆ F.

Sanity check: for every M ≤ 1000 with 3 | M, the class of 1 is reachable from every class in the exact
residue graph.

## Theorem C (m3_e): cycles with few non-multiples of 3

A cycle has terms n_1..n_k not divisible by 3, and K divisions by 3 in total. Then
∏ (7 + r_i/n_i) = 3^K with r_i ∈ {1,2}. So 7^k < 3^K ≤ (7 + 2/n_min)^k, and n_min ≤ B_k, the largest n with
(7n+2)^k ≥ 3^{K_0} n^k. Here K_0 is least with 3^{K_0} > 7^k. Exhaustive exact search (same method as
CLS-032.md) shows that **the only cycles with at most 1000 terms not divisible by 3 are {1,9,3} and the
14-cycle (4,30,10,72,24,8,57,19,135,45,15,5,36,12)**. Hence every eventually periodic orbit ends in one of
these two cycles or in a cycle with more than 1000 non-multiples of 3.
