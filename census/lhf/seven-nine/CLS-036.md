# CLS-036 — 9n+1, FATE of 5

Map: even n -> n/2; odd n -> 9n+1. Question: does the orbit of 5 return to 5, enter another cycle,
or grow forever?

**Status: PARTIAL (OPEN).**

Proved (proofs in CLS-032.md, Theorems A and C with q = 9; see also CLS-037.md):

1. **9n+1 has no cycle with ≤ 1000 odd terms** (checked exactly; ≤ 3000 in an extra run). So the orbit of 5
   either grows without bound or ends in a cycle with more than 1000 odd terms. In particular, if 5 is
   periodic, its cycle has more than 1000 odd terms. Note 1 -> 10 -> 5, so this is also the orbit of 1.
2. **No congruence separator exists at any modulus.** Theorem A says the forward residue-graph closure
   of any class contains the class of 1, and so the classes of 10 and 5. This proves for every M what the
   census notes checked for M ≤ 3000. Congruence arguments cannot decide even the "return to 5" part.
3. "Grows forever" would imply GLOBAL (CLS-037) = "no". If 9n+1 has no cycles at all, the answer is
   "grows forever".

Check: `check_CLS-036.py` (exit 0).

The author's check scripts also pass (exit 0, 3-9 s each).

Proof re-derivation, checked line by line and correct:
- Step 1, the 2-adic (or 3-adic) loss: q is invertible mod 2^{a-b}.
- Step 2: R_m is closed under h and h∘g, and hence under g, since h has finite order.
- Step 3: on Z/m', D^{-1} g D g^{-1} is x -> x - 1/2 (for m3_e, g_1 g_2^{-1} is x -> x + 1). On Z/p^e, g^j is constant for j >= e, and that constant is a unit in <2> (in <3> for m3_e), by LTE or primitivity.

Theorem C: the product identity prod(q + r_i/n_i) = base^K and the monotone bound that gives B_k are correct, and the enumeration is exhaustive for k <= L.

Strengthening noted by the referee (not needed for the verdict): Theorem A also covers truncated traps F = {n >= N : n mod M in R}. Steps 1-3 go through for elements >= N, so F contains every large n = 1 mod m. It therefore contains some 2^j (3^j for m3_e), whose forward orbit reaches 1. Hence 1 is in F.
