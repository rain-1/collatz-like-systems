# CLS-032 — 7n+1, GLOBAL (also the home of Theorems A and C for qn+1, q = 7, 9)

Map U: even n -> n/2; odd n -> 7n+1. Question: is every positive orbit eventually periodic?

**Status: PARTIAL (GLOBAL itself remains OPEN).** Proved here:

* **Equivalence:** CLS-034 is the same question word for word: same map, and GLOBAL does not
  depend on the seed tag. CLS-035 (7n+7 GLOBAL) is exactly equivalent to it; see CLS-035.md.
* **Theorem A (obstruction to congruence traps, every modulus).** Let F be a nonempty set of positive integers
  that is a union of residue classes mod some M with U(F) ⊆ F. Then 1 ∈ F. So no set of
  residue classes, at any modulus, can certify a divergent orbit, which is route (a) of the
  low-hanging-fruit list. Nor can any congruence argument rule out that a given orbit reaches the cycle
  {1,8,4,2}. This replaces the finite separator searches (moduli up to 800 or 3000) in the census notes
  with a proof for every modulus.
* **Theorem C (cycles with few odd terms).** The only cycle of 7n+1 with at most 1000 odd terms is {1,8,4,2}.

Check: `check_CLS-032.py` (exit 0, about 10 s).

## Theorem A (stated for T_q: even n -> n/2, odd n -> qn+1, with q = 7 or q = 9)

Let p be the prime dividing q (p = 7 or 3). Let F ⊆ Z_{>0} be nonempty with T_q(F) ⊆ F, where
F = {n > 0 : n mod M ∈ R} for some modulus M and some set R. Then 1 ∈ F.

**Proof.** Replacing M by 2M, we may assume M = 2^a m with a ≥ 1 and m odd. For 0 ≤ b ≤ a write
P(c,b) = {n > 0 : n ≡ c (mod 2^b m)}. This is a union of M-classes.

*Step 1: the 2-adic information is lost.* Suppose P(c,b) ⊆ F with b ≥ 1.
- If c is even, then T(P(c,b)) = P(c/2, b-1). If n' ≡ c/2 (mod 2^{b-1}m) then 2n' ∈ P(c,b) and T(2n') = n'.
  So P(c/2, b-1) ⊆ F.
- If c is odd, then T(c + 2^b m t) = (qc+1) + q·2^b m t. As t runs, q·2^b m t mod M runs over all
  multiples of 2^b m, because q is odd and hence invertible mod 2^{a-b}. So T(P(c,b)) meets every
  M-class inside P(qc+1, b). F is a union of M-classes, so P(qc+1, b) ⊆ F. Here qc+1 is even.

Start from any M-class P(c_0, a) ⊆ F. Odd steps keep b and are followed by an even step, which
lowers b by 1. After at most 2a steps we reach some full class P(s, 0) = {n ≡ s mod m} ⊆ F.

*Step 2: the induced action on Z/m.* Let R_m = {s mod m : P(s,0) ⊆ F}; it is nonempty. If s ∈ R_m, then
P(s,0) contains the class P(s_e,1) with s_e even and P(s_o,1) with s_o odd (both ≡ s mod m). Step 1
with b = 1 gives P(s/2 mod m, 0) ⊆ F, and P(q s_o + 1, 1) ⊆ F, then P((qs+1)/2 mod m, 0) ⊆ F.
So R_m is closed under h(x) = x·2^{-1} and h∘g, where g(x) = qx+1 (on Z/m). h is a permutation of
the finite set Z/m, so h^{-1} = h^{N-1} for its order N. Hence R_m is closed under g = h^{N-1}∘(h∘g) and
under every word in g and h.

*Step 3 (Lemma): for every odd m and every s ∈ Z/m some word in {g, h} sends s to 1.* Then 1 mod m ∈ R_m,
so 1 ∈ P(1,0) ⊆ F, which proves the theorem.

Write m = p^e m' with p ∤ m' (e ≥ 0); gcd(m', 2q) = 1. By the CRT we work on Z/p^e × Z/m'.
- g^j(x) = q^j x + c_j with c_j = 1 + q + ... + q^{j-1}. For j ≥ e, q^j ≡ 0 (mod p^e), so g^j is
  *constant* ≡ c_j mod p^e, and c_j ≡ 1 (mod p).
- Units ≡ 1 mod p are powers of 2 mod p^e. Let x_0 = 8 (p = 7) or x_0 = 4 (p = 3). Then x_0 ≡ 1 (mod p) and
  x_0 ≢ 1 (mod p^2). By lifting the exponent, v_p(x_0^{p^i} − 1) = 1 + i, so x_0 has order p^{e-1}
  mod p^e. That is the order of the group of units ≡ 1 mod p, so this group equals ⟨x_0⟩ ⊆ ⟨2⟩.
  Hence c_e = 2^β for some β ≥ 0, and h^β(c_e) = 1 mod p^e.
- On Z/m', g and h are permutations (q and 2 are units). Write D = h^{-1} (x -> 2x). Then
  g D g^{-1}(x) = q·2·(x−1)/q + 1 = 2x − 1, so D^{-1} g D g^{-1}(x) = x − 1/2. This is a translation by a
  unit, so its powers act transitively.
- Choose N_0 ≥ e+1 that is a common multiple of the orders of g and h as permutations of Z/m'. Put
  τ = h ∘ g ∘ h^{N_0−1} ∘ g^{N_0−1}. On Z/m' this is D^{-1} g D g^{-1}: x -> x − 1/2. On Z/p^e it is
  constant (g^{N_0−1} is constant there), with value d say. So τ^j(s) = (d, s' − j/2) for j ≥ 1.
  Let ω = h^β ∘ g^e. Then ω(d) = h^β(c_e) = 1 mod p^e, and ω is a permutation π of Z/m'. Choose j ≥ 1
  with s' − j/2 ≡ π^{-1}(1) (mod m'). Then ω τ^j (s) ≡ 1 (mod m).
  (If e = 0, drop the p-part. If m' = 1, ω alone works.) ∎

**Consequences.**
(1) A nonempty union of classes, at any modulus, that is forward-closed contains the periodic point 1.
    So it cannot consist of divergent orbits, and route (a) via congruence traps is impossible for 7n+1
    and 9n+1.
(2) For any seed n_0 and any M, the forward closure of n_0's class in the residue graph mod M contains
    the class of 1. So no congruence separator can show that an orbit avoids the 1-cycle. For 9n+1
    it also cannot avoid 5 = T^2(1) (this settles the "no separator up to 3000" search of CLS-036 for
    every modulus).
(3) This says nothing against non-congruence certificates (e.g. archimedean or automaton-with-size
    arguments).

Computational sanity (`check_CLS-032.py`, `check_CLS-037.py`): for every even M ≤ 1000, the class of 1
is reachable from every class in the exact residue graph mod M.

## Theorem C (cycles of T_q with k odd terms; q = 7, 9)

Let a cycle have odd terms n_1, ..., n_k. Let K be the total number of halvings in one turn of
the cycle. Multiplying n_{i+1}/n_i over the cycle gives ∏ (q + 1/n_i) = 2^K. Hence q^k < 2^K. If n_1 is the
least odd term, then 2^K ≤ (q + 1/n_1)^k. With K_0 the least integer such that 2^{K_0} > q^k, we get
(q n_1 + 1)^k ≥ 2^{K_0} n_1^k. Let B_k be the largest n satisfying this; it is computed exactly with integers.
Every cycle with k odd terms therefore has least odd term ≤ B_k.

For each odd n we take K(n) = max{k ≤ L : B_k ≥ n} and iterate the accelerated odd-to-odd map from n
at most K(n) times. We stop early if a value ≤ n appears: a value < n shows that n is not the least
odd term of any cycle, and a value = n means a cycle was found. This decides exactly every cycle with
k ≤ L odd terms. Results:

* 7n+1, L = 1000 (all odd n ≤ 346630 tested): only {1,8,4,2}.
* 9n+1, L = 1000 (n ≤ 97214): **no cycle at all**. A separate run with L = 3000 (n ≤ 464416, 149 s, same code
  `sevnine_lib.cycles_up_to('P9', 3000)`) also finds none.

Consequence for 7n+1: every orbit is unbounded, reaches {1,8,4,2}, or enters a cycle with more than 1000
odd terms.

## Referee (adversarial check)

**Verdict: CONFIRMED for q = 7, with one correction to the q = 9 consequence.** Theorem A (every modulus) and Theorem C (L = 1000) were re-derived and checked independently. Correction: Consequence (1), that route (a) is impossible for 9n+1, does NOT follow. For 9n+1 the point 1 is not known to be periodic; Theorem C even shows it is on no cycle with at most 1000 odd terms. If 9n+1 had no cycles, Z_{>0} itself would be a valid divergence trap. The correct statement for q = 9: every congruence trap contains the orbit of 1, so any route-(a) certificate would in particular prove that orbit (CLS-036) unbounded. For q = 7 the consequence is correct, because 1 is periodic. GLOBAL stays OPEN.

Independent test: `referee_check.py` (exit 0, about 55 s; written without sevnine_lib, uses the census/systems.py steps). It checks Theorem A at **every** modulus M <= 240 (odd moduli included, with the residue graph built from actual images of r+Mt), the Step-3 lemma directly on Z/m for all admissible m < 1500, and Theorem C with an independent implementation (B_k by binary search; the full, unaccelerated map). The author's check scripts also pass (exit 0, 3-9 s each).

Proof re-derivation, checked line by line and correct:
- Step 1, the 2-adic (or 3-adic) loss: q is invertible mod 2^{a-b}.
- Step 2: R_m is closed under h and h∘g, and hence under g, since h has finite order.
- Step 3: on Z/m', D^{-1} g D g^{-1} is x -> x - 1/2 (for m3_e, g_1 g_2^{-1} is x -> x + 1). On Z/p^e, g^j is constant for j >= e, and that constant is a unit in <2> (in <3> for m3_e), by LTE or primitivity.

Theorem C: the product identity prod(q + r_i/n_i) = base^K and the monotone bound that gives B_k are correct, and the enumeration is exhaustive for k <= L.

Strengthening noted by the referee (not needed for the verdict): Theorem A also covers truncated traps F = {n >= N : n mod M in R}. Steps 1-3 go through for elements >= N, so F contains every large n = 1 mod m. It therefore contains some 2^j (3^j for m3_e), whose forward orbit reaches 1. Hence 1 is in F.
