# CLS-057 [qrA3_q17]: the q=17 theorem holds for the whole mixed-multiplier family A_m(q)

**Item.** For T(n) = n/2 when n is even and T(n) = (n+17c)/3 with c = n mod 3 when n is odd, the question asks for a finite-state rule that decides whether n reaches (1 6 3) or (5 13 10), or a proof that no such rule exists.

**Status of the item: already RESOLVED (negative) by commit 36553ef.** No integer base k >= 2 admits such a rule; the proof is in `census/round2/qr/qrA3_q17.md`, and the lanes q17-nonauto and q17-structure audited it independently. The entry in `census/open_collatz_systems.txt` is stale.

**This lane: PROVED, a family generalization.** This lane was asked to understand q=17 through its family. The result below explains what separates the mixed-multiplier family from the halving-only family B. It also gives the smallest members and answers the question about invariants.

## Family theorem

Fix an odd m >= 3 (m need not be prime) and an integer q >= 2 with gcd(q, 2m) = 1. Define

  T(n) = n/2 if n is even;  T(n) = (n + c q)/m if n is odd, where c in [0, m-1] is the unique digit with m | n + cq.

Let H = <2, m> be the subgroup of (Z/q)^*.

**Theorem F.** Let G be a coset of H in (Z/q)^* that contains at least two cycles of T, and let C be any cycle in G. Then for every k >= 2 the indicator of basin(C) is not k-automatic. If G contains exactly two cycles C1 and C2, then no DFA reading base-k digits separates basin(C1) from basin(C2) for any k.

For (q, m) = (17, 3) this recovers the CLS-057 theorem. It also covers every q in {17, 53, 67, 71, 97, 107, 109, ...} for m = 3, and every multiplier m. The proof needs no extra hypothesis. In particular it allows cycles made only of odd steps, which occur for example at (q, m) = (121, 3), where (1 81 27 9 3) contains no halving.

### Proof

**(0) Descent, invariants and dilations.** For an odd n > q we have T(n) <= (n + (m-1)q)/m < n, and T maps [1, q] into itself. So every orbit enters a cycle inside [1, q].

- Each step multiplies n by 2^{-1} or m^{-1} mod q. Hence gcd(n, q) is invariant, and for units so is the H-coset. Consequently basin(C) is contained in the units of G.
- f(2n) = f(n) holds because T(2n) = n.
- f(mn) = f(n) holds for every n. Write n = 2^s u with u odd. Then mu is odd and divisible by m, so c = 0 and T(mu) = u.

**(1) Odd predecessors.** For odd y, define three maps:
- L(y) = my, with c = 0;
- R(y) = my - 2q, with c = 2, which is a valid digit since m >= 3;
- S(y) = 2my - q.

Each value is odd. They satisfy T(L y) = T(R y) = y and T(T(S y)) = T(2y) = y; for S(y) the digit is c = 1. When y >= q, each map gives a value >= y.

**(2) Lemma (rough).** Let Q >= 1 with gcd(Q, m) = 1 (Q may be even). Let b and c be odd points of cycles in the same coset G, and let lo be any bound. Then basin(b) contains an odd z >= lo with z ≡ c (mod Q).

*Proof.* L and R are affine maps with slope m, so they permute Z/Q. The finite group they generate contains R L^{-1}, which is translation by -2q. That translation generates the additive subgroup g'Z/Q, where g' = gcd(2q, Q).

Start at y0 = m^N b, where N is a large multiple of ord_Q(m). Then y0 ≡ b (mod Q), y0 >= max(lo, q), and T^N(y0) = b. Apply S^i, then L^j, to get w. Modulo g = gcd(q, Q) we have w ≡ 2^i m^{i+j} b, and w is odd. Since c ≡ h b (mod q) for some h = 2^alpha m^beta in H, choose i and j to match that h. Then c ≡ w (mod g) and c ≡ w (mod 2). Because g is odd, this gives c ≡ w (mod 2g), and hence mod g'.

A suitable power of the translation, written as a positive word in L and R, now moves w to a value z ≡ c (mod Q). Every map used keeps values odd and non-decreasing above q, and z reaches y0 and therefore b. ∎

**(3) Lemma (lift).** Let x -> ... -> c be a forward path whose branch denominators have product A. Then for every y >= c with y ≡ c (mod 2), the number x + A(y - c) follows the same branches and reaches y.

*Proof.* At a step from an odd point the remaining factor contains m, so the m-digit c is unchanged. At an odd step the parity is also unchanged because y - c is even. All intermediate values are at least the original ones. ∎

**(4) Theorem (mix).** Let x be a unit in G, let M >= 1, and let C' be any cycle in G. Then the class x mod M contains arbitrarily large elements of basin(C').

*Proof.* Write M = M_m Q, where M_m is the largest divisor of M whose primes all divide m. Follow x to the first odd point c of its own cycle C_x, and let A be the denominator product of that path.

C_x has a halvings and b odd steps. Its reverse lap has slope Λ = 2^a m^b with b >= 1, because a cycle of positive integers cannot consist of halvings only.

By (2), take a large odd z ≡ c (mod Q) in basin(C'). Put y = c + Λ^t (z - c), with t chosen so that M_m | Λ^t. By (3) applied to t laps, y runs t laps of C_x and reaches z, so y ∈ basin(C').

Moreover y ≡ c (mod M): mod M_m because M_m | Λ^t, and mod Q because z ≡ c (mod Q). So x' = x + A(y - c) ≡ x (mod M), and x' reaches y and hence C'. ∎

Consequence: let G hold two cycles C1 and C2, and let f = 1_{basin(C1)}. Then no section n -> f(Dn + r) whose progression contains an element of G is ultimately periodic.

**(5) Kernel and Cobham step.** Suppose f is k-automatic. Put p = m if k is a power of 2, and p = 2 otherwise; then p and k are multiplicatively independent. Let S be the finite set of k-kernel sections f(k^a n + r), 0 <= r < k^a, that have such a representation whose progression meets G.

For a base-p word of length e and value d, choose D = k^a > 2 q p^e. Among r0 + p^e j for j < q, where r0 = (-Dd) mod p^e, these values cover every residue mod q, so we can pick r < D with r mod q ∈ G.

After reading the first j digits (value d_j), the section is f(p^j(Dn + r_j)) = f(Dn + r_j), where r_j = (D d_j + r)/p^j lies in [0, D). Since r_j ≡ p^{-j} r (mod gcd(D, q)) and p^{-j} r ∈ G, the progression Dn + r_j meets G. So every word is readable within S from some state.

The elimination argument from qrA3_q17.md then gives one state s* ∈ S whose entire p-kernel lies in S. That state is both p-automatic and k-automatic, so Cobham's theorem makes it ultimately periodic. This contradicts (4).

For the separation claim with exactly two cycles in G, note that f(n) = [n mod q ∈ G] · DFA(n), because basin(C1) ⊆ G. A separating DFA would therefore make f k-automatic. ∎

## What distinguishes family A from family B (qrB7_c53)

In family B (halving only), T drops the low bit and adds a bounded carry, which a finite 2-adic transducer can do. For qrB7_c53 the basin is 2-automatic, even though cycles 3 and 5 lie in the same <2>-coset {3, 5, 6} of (Z/7)^*.

The proof of Theorem F uses exactly one feature that family B lacks: two multiplicatively independent dilation symmetries, f(2n) = f(n) = f(mn). Together with the mix theorem, these feed Cobham's theorem. So what decides non-automaticity is the mixing of multipliers (2 and m), not the coset structure.

## Invariants for q = 17 (requested)

Every invariant in the following list is ruled out, as a corollary of (4) with q = 17, m = 3:
- any finite-valued 2-adically or 3-adically continuous function, since such a function is a congruence mod 2^j or 3^j;
- any character of (Z/17^2)^* or of (Z/17^e)^*, or more generally any function of n mod M;
- any function of (n mod M, v_2(n), v_3(n)): take x ≡ 1 (mod 6), and then the class x mod 6M contains both basins with v_2 = v_3 = 0;
- any k-automatic quantity for any k.

The check confirms numerically that every unit class mod 289 and mod 2^4·3^3·17 contains both basins, for n < 4·10^5.

Since every k-automatic invariant fails, an exact description has to carry unbounded state, for example the branch word (parity and digit vector) of the orbit.

## Referee

**Verdict: CONFIRMED (Theorem F is new and correct). For the CLS-057 item itself this lane adds nothing: the item was already settled by commit 36553ef.**

What the referee re-derived by hand:
- **(0) Descent.** For odd n > q, T(n) < n holds because (m-1)q < (m-1)n.
- **(0) Invariants.** gcd(T(n), q) = gcd(n, q) because m T(n) = n + cq and gcd(m, q) = 1. The coset is invariant because T(n) ≡ n·m^{-1} or n·2^{-1} (mod q).
- **(0) Dilations.** f(mn) = f(n) holds for all n, since c = 0 on m·(odd).
- **(1) Predecessor maps.** L, R and S have digits 0, 2 and 1, all valid because m >= 3. They give odd values that are >= y once y >= q, because (m-1)y >= 2y >= 2q.
- **(2) Lemma (rough).** The word R L^{o-1} acts as the integer map y -> m^o y - 2q, which is translation by -2q mod Q. The reduction mod g lifts to mod 2g because both values are odd and g is odd, and gcd(2q, Q) divides 2·gcd(q, Q). Positive exponents i and j realising any element of H exist because H is finite.
- **(3) Lift lemma.** Checked step by step. At an odd step m | A_i, so the digit is unchanged, and y - c is even, so the parity is unchanged. At an even step A_i = 2A_{i+1}.
- **(4) Mix theorem.** z ≡ c (mod Q), z odd and z > c give y ≡ c (mod M_m Q). y is also odd, so the lift applies.
- **(5) Kernel and Cobham step.** Checked:
  - p^j divides D d_j + r, and r_j < D.
  - r_j ≡ p^{-j} r (mod gcd(D, q)), with p^{-j} r in G because p ∈ H.
  - The elimination argument works on the functions themselves, so it is independent of the chosen representation.
  - p and k are multiplicatively independent in both cases.
- **Separation corollary.** f = [n mod q ∈ G]·DFA(n) is valid because non-units keep gcd(n, q) and cannot reach a unit cycle.

**Novelty.** The notes file and the 36553ef tex treat only q = 17, m = 3. The family statement is new: any odd m, any composite q, cycles made only of odd steps, and even moduli Q in Lemma (2).
