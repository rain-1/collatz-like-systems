# perm_1932_s44

**Common facts (tier 1).** (i) The map is a bijection of the positive integers: each residue-class branch is an increasing affine bijection from its class onto one target class, and the target classes partition Z_{>0} (checked algebraically; spot-checked against an explicit inverse in the check script). (ii) For an injective map, fate (b) is impossible: if the orbit of x first meets a cycle C at y=T^k(x) with k>=1 and x not in C, then y has two distinct preimages (T^{k-1}(x) and its predecessor in C). So FATE is "returns" or "infinite". (iii) For a bijection, "every orbit eventually periodic" means "every orbit is a finite cycle".

**FATE.** Direct computation: 44 -> 59 -> 79 -> 105 -> 70 -> 93 -> 62 -> 83 -> 111 -> 74 -> 99 -> 66 -> 44. (This is the known 12-cycle; Lagarias lists the known cycles of T as {1}, {2,3}, {4,5,7,9,6}, {44,...,66}.)

**GLOBAL (OPEN, tier 5).** Every orbit of T periodic would in particular make the orbit of 8 finite; this is exactly Collatz's 1932 question (Lagarias, "The 3x+1 problem and its generalizations", 1985; Lagarias' annotated bibliography) and is open. Conversely "no" needs one provably infinite orbit, which is also unknown for T. Heuristic log-drift is (1/3)log(32/27) > 0 forward and (1/2)log(9/8) > 0 backward, predicting infinite orbits for almost all n, but no orbit has been proved infinite. Congruence tools fail: for seed 8 there is no forward-closed union of residue classes mod M separating 8 from T(8) for any M <= 150 (checks/perm_1932_s8.py); the unreviewed reference certificate_search_proofs.txt section 5 argues the residue graph is strongly connected for every M, so no periodic separator exists at any modulus.
