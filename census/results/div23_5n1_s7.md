## FATE

## GLOBAL: what was tried
* Accelerated form: for n coprime to 6, n -> (5n+1)/(2^v2 * 3^v3), with v2 >= 1 and v3 >= 0 the full 2- and 3-adic valuations of 5n+1.
* Heuristic drift: E[v2] = 2. 5n+1 = 0 mod 3 iff n = 1 mod 3, so E[v3] = 3/4. The mean log step is ln5 - 2ln2 - (3/4)ln3 = -0.60 < 0, so orbits should converge, but this is only a heuristic. Descending this way is exactly the Collatz-type obstacle: there is no bound on how many large-growth steps happen in a row. For instance n = -1/5 in the 2-adic integers keeps v2 unbounded, and residue classes realise any finite valuation pattern.
* Congruence invariants: none exist. Every residue class mod 2^a 3^b is entered, and the map is a generalized Collatz (Conway-type) map with 3 multipliers and no trapping class.
* Simulation (exploratory run to 10^6; checks re-run to 2*10^5): every n <= 10^6 drops below its start or closes a cycle, and the only cycle found is {1, 6, 3}.
* No conjugacy to a solved map was found. The question has the same nature as the 3x+1 conjecture: it asks for convergence of a mixed-modulus affine map with negative drift. It is not literally equivalent to any named problem we know of. Descent with a finite table fails because the stopping time is unbounded (it reached 140 steps below 10^6 and grows with n). Automaton or QR invariants do not apply, because no residue class is invariant.

## Referee
Verdict: FATE confirmed (tier 0, by exact simulation to the cycle). GLOBAL open-agreed (tier 5).
I re-ran the check and also surveyed every n <= 10^6 myself. My maximum stopping times match the stated ones (5n+1: 140 at n=986231; 7n+1 with /2,/3,/5: 220 at n=468109; 7n+1 with /2,/3: 9767 at n=966791, reaching 163 bits; the 34-cycle with min 19 and max 20168 is confirmed). The drift values are correct: E[v2] = 2, and the probabilities that 3 and 5 divide the image are 1/2 and 1/4.
Why tiers 1-3 fail: on the 2-adic and 3-adic side, the growth branch (an image with v2 = 1 and no other small-prime factor) is an affine bijection between residue classes. So any finite pattern of growth steps is realised by a nonempty residue class, by CRT. That makes stopping times unbounded and rules out any finite descent table or congruence-closed trap. I could find no conjugacy, automaton or coset invariant. Proving convergence would need control over orbit statistics of the kind that is missing for 3x+1 itself, so I regard this as genuinely of Collatz difficulty. It is not literally a named problem.
