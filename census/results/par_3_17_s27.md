## GLOBAL (OPEN)
This is an instance of Lagarias' 3x+k problem (k = 17), open for every k. Moreover it contains the
Collatz problem: 17Z is invariant (if 17 | n then 17 | 3n+17 and 17 | n/2) and T(17 m) = 17*C(m) with C the
3x+1 map (checked for m <= 2e5 in the check script; algebraically 3*17m+17 = 17(3m+1)). So a proof that
every orbit is eventually periodic would prove that 3x+1 has no divergent trajectory. Unlike 3x+9 the
converse reduction fails: orbits with gcd(n,17)=1 never enter 17Z (17 prime, 3n+17 = 3n mod 17), so the global question
is strictly at least as hard as the divergence half of Collatz. No elementary/congruence/automaton tool
applies (each would already settle 3x+1 on the invariant sublattice).
