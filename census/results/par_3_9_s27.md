## GLOBAL (OPEN, equivalent to a famous open problem)
Let C(y) be the Collatz map (y/2 or 3y+1).
1. If n is odd, T(n) = 3(n+3) is divisible by 3; halving preserves divisibility by odd numbers. So 3Z is invariant and every positive orbit (which must contain odd terms; it cannot halve forever) enters 3Z.
2. On n = 3m: T(3m) = 3*S(m) with S the 3x+3 map; S(odd m) = 3(m+1), so likewise every S-orbit enters 3Z. Hence every T-orbit enters 9Z.
3. On n = 9y: T(9y) = 9*C(y) (27y+9 = 9(3y+1)). So T on 9Z is exactly conjugate to Collatz.
Therefore every positive T-orbit is eventually periodic iff every positive Collatz orbit is eventually periodic (=> direction: orbit of 9y). This is the "no divergent trajectories" half of the 3x+1 conjecture, open. Tools that fail: no descent/congruence/automaton argument is known for 3x+1 itself.
