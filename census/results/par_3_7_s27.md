## Referee
FATE: confirmed (tier 0). GLOBAL: open-agreed (tier 5).
The independent simulation agrees with the claimed tail and cycle, and the cycle does not contain 27.
7Z is forward invariant: an even multiple of 7 halves to a multiple of 7, and for odd m, 3(7m)+7 = 7(3m+1). So F(7m) = 7C(m), which I asserted for m < 10^5.
A "yes" to GLOBAL would therefore imply Collatz no-divergence. A "no" would need a divergent 3x+7 orbit, which is also unproven. So GLOBAL contains an open problem but is not stated to be equivalent to one, and that framing is correct.
