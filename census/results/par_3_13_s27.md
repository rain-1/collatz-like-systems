## GLOBAL (OPEN)
This is an instance of Lagarias' 3x+k problem (k = 13), open for every k. Moreover it contains the
Collatz problem: 13Z is invariant (if 13 | n then 13 | 3n+13 and 13 | n/2) and T(13 m) = 13*C(m) with C the
3x+1 map (checked for m <= 2e5 in the check script; algebraically 3*13m+13 = 13(3m+1)). So a proof that
every orbit is eventually periodic would prove that 3x+1 has no divergent trajectory. Unlike 3x+9 the
converse reduction fails: orbits with gcd(n,13)=1 never enter 13Z (13 prime, 3n+13 = 3n mod 13), so the global question
is strictly at least as hard as the divergence half of Collatz. No elementary/congruence/automaton tool
applies (each would already settle 3x+1 on the invariant sublattice).
